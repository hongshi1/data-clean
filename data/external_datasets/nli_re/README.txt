This file contains the dataset used for 2024 IEEE International Requirement Engineering Conference paper, titled: Lessons from the Use of Natural Language Inference (NLI) in Requirements Engineering Tasks.


There are 3 tasks studied in this paper, and we presented two new datasets for tasks 2 and 3.


Task 1: Classification of software requirements into functional and a variety of non-functional requirements.


Task 2: Identification of various forms of requirements specification defects


Task 3: Detection of conflicting requirements


Tasks 1 and 2, each has only one file.


Task 1 file represents the Promise dataset


The file for Task 2 represents one of the datasets we compiled, which contains software requirements specification defects.


Task 3 contains 7 files: Promise (projects: p2, p6, p10), Broker (which we compiled), and three public datasets ETCS, Library, CoffeeMachine


For Task 3, for each dataset, we provided another file containing the conflicting requirements.
