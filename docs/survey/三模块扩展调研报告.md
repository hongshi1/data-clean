## 对研究方案的关键影响

### 1. 方法baseline大幅丰富
之前只有FAMDR可迁移，现在有：
- **DIVER** — 完整的跨模态一致性验证框架
- **VDC** — MLLM驱动三模块不一致检测
- **Cross-Modal Error Detection** — 直接的表格+图片跨模态错误检测baseline
- **MM-GoT** — 3种验证信号设计

### 2. 实验数据集选择更多
- **Cross-Modal Error Detection的4个数据集** — 直接可用的表+图跨模态错误检测数据
- **TABARD** — 表格不一致检测基准（8种异常含"一致性"）
- **MM-TS** — 大规模三模态数据（如果需要时序实验）

### 3. 工具生态更完整
- **OmniVerifier** — 可直接集成的视觉验证器
- **MMCDF** — 开源的跨模态不一致检测框架（可参考或直接用）
- **lmms-eval** — 统一评估框架

### 4. 研究定位更清晰
对比新发现，我们的差异化价值在于：
- **军工领域** — 所有现有方法都在通用/医疗/新闻领域
- **三模态组合(表+图+时序)** — 现有方法最多做两模态
- **Data-Juicer扩展** — 将"过滤"工具改造为"验证"工具
- **军工知识图谱接入** — 现有方法不用领域本体做约束传播
