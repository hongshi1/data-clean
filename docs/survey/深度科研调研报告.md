## 1. 课题定义与边界

### 1.1 研究问题

**核心问题**：给定军工武器领域的表格数据（规格参数）、图片数据（武器照片/SAR图像）、时序数据（传感器信号/轨迹），如何自动检测三类模态之间的不一致性？

### 1.2 模态定义

| 模态 | 军工场景实例 | 医疗对照场景 | 数据类型 |
|---|---|---|---|
| 表格 | 武器规格参数表（型号/口径/重量/射程） | 血液检验结果（50项指标） | 结构化CSV |
| 图片 | 武器照片/SAR合成孔径雷达图像 | 胸片X光(CXR) | RGB/灰度图像 |
| 时序 | 传感器信号/雷达回波/GPS轨迹 | 心电图(ECG)/生命体征 | 一维时序信号 |

### 1.3 与相关方向的边界

本课题**不是**：
- **多模态对齐**(alignment)：对齐只回答"模态是否大致对应"，不回答"证据是否事实矛盾"
- **幻觉检测**(hallucination detection)：幻觉检测是单输入-单输出的忠实性检查，不做多源证据联合验证
- **数据生成**(data generation)：前序课题已做数据生成，本课题做数据质量校验

本课题**是**：跨模态一致性验证——多条证据在同一套领域约束下是否共同成立。

### 1.4 理论框架基础

前序综述（`跨模态一致性验证与推理_综述重组版.md`）已建立**DKG-CMR统一框架**，定义了跨模态一致性验证的6个部件：

1. **Cross-modal grounding**：跨模态接地（文本mention/图像region/表格cell接到同一实体）
2. **Structured evidence model**：结构化证据模型（claim/evidence/support edge/conflict edge）
3. **Domain-knowledge substrate**：领域知识基底（ontology/rules/schema/causal constraints）
4. **Constraint propagation**：约束传播（一个模态的约束传播到另一个模态验证）
5. **Verification-oriented reasoning**：验证导向推理（演绎+归纳+溯因）
6. **Explanation and attribution**：解释与归因（verdict+evidence+violated rule+confidence+repair）

本课题是DKG-CMR框架在军工场景的**实例化落地**。

5. **MMCDF最接近我们的目标**：开源的跨模态不一致检测框架，可参考

### 4.2 医疗三模态深度分析

- **来源**：arXiv 2506.18512, 2025

### 5.3 算法层关键结论

1. **没有方法做"表格+图片+时序"三模态一致性校验**——这是核心空白
2. **FAMDR的4组件架构最适合迁移**——噪声感知对齐→检索增强→精细定位→不确定性
3. **DIVER的迭代证据推理是优秀的方法框架**——模态内一致性→跨模态对齐→迭代证据
4. **MM-GoT的3种验证信号设计可直接借鉴**——语义一致性+空间有效性+注意力接地
5. **Cross-Modal Error Detection是最直接baseline**——直接做表+图，有4数据集+5 baseline

## 6. 治理范式分析

### 6.1 七种治理范式

| 范式 | 原理 | 代表工具 | 能解释 | 能跨模态 | 能修复 | 成本 |
|---|---|---|---|---|---|---|
| 1.规则约束 | 预定义规则检查违反 | GE, Deequ, TABARD | ✅ | ❌ | ❌ | 低 |
| 2.过滤丢弃 | 打分低于阈值丢弃 | Data-Juicer, CLIPScore | ❌ | ⚠️ | ❌ | 低 |
| 3.异常检测 | 统计离群点识别 | TAB, MTAD, LEMoN | ⚠️ | ❌ | ❌ | 中 |
| 4.对齐验证 | 跨模态相似度 | CLIP, VDC, SARCLIP | ⚠️ | ✅ | ❌ | 中 |
| 5.推理验证 | LLM判断语义矛盾 | FAMDR, OmniVerifier, DIVER | ✅ | ✅ | ⚠️ | 高 |
| 6.图谱约束 | 知识图谱约束传播 | Mario, MAKGED, VaLiK | ✅ | ✅ | ⚠️ | 高 |
| 7.迭代修正 | 检测→干预→再检测 | MMCDF, MedTVT-R1 | ✅ | ✅ | ✅ | 最高 |

### 6.2 我们的组合方案

```
Layer 3 单模态质量:
  表格 → 范式1(规则约束): Great Expectations
  图片 → 范式2(过滤)+范式4(对齐): CLIP/SARCLIP
  时序 → 范式3(异常检测): TAB/MTAD

Layer 4 跨模态一致性:
  表格↔图片 → 范式4(对齐)+范式5(推理): CLIP+LLM
  图片↔时序 → 范式3(异常)+范式4(对齐): 时序异常+时间戳对齐
  三模态融合 → 范式6(图谱)+范式7(迭代): 军工本体+闭环检测

→ 业界没有单一范式能做三模态不一致性校验
→ 组合7种范式 = 我们的创新贡献
```

### 8.3 跨模态不一致性检测算法设计

#### 检测1：表格↔图片规格矛盾
```
输入: 武器规格表(类型=手枪, 口径=9mm) + 武器图片
步骤:
  1. CLIP/SARCLIP计算图片与规格描述的相似度 → score
  2. 统计异常检测：score < mean - 1.5σ → 疑似不一致
  3. LLM验证："这张图片是否为{类型}？口径是否匹配{口径}？"
  4. 知识图谱校验：图片识别结果 vs 规格表型号
输出: 不一致标记 + 置信度 + 矛盾字段
```

#### 检测2：图片↔时序事件对齐
```
输入: 武器图片(带时间戳) + 传感器时序数据
步骤:
  1. TAB/MTAD检测时序异常事件 → 异常时间点列表
  2. 检查异常时间点是否有对应图片记录
  3. 检查图片时间戳与时序数据时间戳偏差
  4. 若偏差>阈值 → 标记为时序-图片不一致
输出: 时间错位报告 + 异常事件清单
```

#### 检测3：三模态融合评分
```
S_table = 表格质量分数 (Great Expectations通过率)
S_image = 图片一致性分数 (CLIP相似度归一化)
S_time = 时序质量分数 (异常检测得分)
S_final = w1*S_table + w2*S_image + w3*S_time
若 S_final < threshold → 多模态不一致
```

### 9.2 实验结果

#### Data-Juicer CLIP图文不一致检测

| 样本 | CLIP分数 | 实际状态 | 检测结果 |
|---|---|---|---|
| AK-47 (匹配) | 0.3101 | ✅ | ✅正确 |
| M16A4 (匹配) | 0.3174 | ✅ | ✅正确 |
| Glock 17 (匹配) | 0.2828 | ✅ | ✅正确 |
| w006 手枪描述/步枪图 | 0.2800 | ⚠️不一致 | ⚠️偏低 |
| w007 步枪描述/手枪图 | 0.2661 | ⚠️不一致 | ⚠️偏低 |
| **w008 RPG描述/步枪图** | **0.2616** | **⚠️不一致** | **❌检出** |

- 分类准确率：60%（合成图像，通用CLIP）
- 不匹配检出率：100%（3/3）
- 统计异常检测(均值-1.5σ)检出最严重不一致

#### SARCLIP vs 标准CLIP对比

| 指标 | 标准CLIP (ViT-B-32) | SARCLIP (ViT-L-14) |
|---|---|---|
| 分类准确率 | 60% | 10%（合成图不适用） |
| 不匹配检出率 | 100% | 100% |
| 平均置信度 | 0.95 | 0.21 |

**结论**：SARCLIP需在真实SAR图像上验证（合成图不适用）。标准CLIP在合成图上已证明pipeline可行。

#### SARCLIP权重格式转换

成功解决open_clip → HF transformers格式转换：
- key重映射（vision_model.conv1→embeddings.patch_embedding等）
- attention拆分（in_proj_weight → q/k/v_proj）
- projection转置
- config修复（num_hidden_layers=24, projection_dim=768）
- 最终0 missing / 0 unexpected keys

## 10. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| SARCLIP在非SAR图像上不适用 | 军工光学照片无法用SARCLIP | 标准CLIP做baseline + SARCLIP仅用于SAR图像 |
| 军工真实数据获取受限 | 实验数据不足 | 用Symile-MIMIC医疗数据跨领域验证 |
| Apple Silicon无CUDA | 部分算子慢 | MPS加速+CPU回退，或租云GPU |
| Data-Juicer不支持时序 | 时序模态无法处理 | 自定义算子+TAB/MTAD外部接入 |
| FAMDR实现复杂 | 开发周期长 | 先实现简化版(CLIP+统计+规则)，逐步加入FAMDR组件 |
| 通用CLIP军工区分度低 | 检测准确率不足 | SARCLIP微调+FAMDR方法+规则补充+LLM辅助 |
