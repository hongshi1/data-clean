## 一、已验证并跑通的三模态数据集

### 1. OLIVES Dataset (眼科)

| 维度 | 内容 |
|---|---|
| **论文** | "OLIVES Dataset: Ophthalmic Labels for Investigating Visual Eye Semantics" |
| **Venue** | NeurIPS 2022 Datasets and Benchmarks |
| **作者** | Prabhushankar et al. (Georgia Tech + Retina Consultants of Texas) |
| **arXiv** | 2209.11195 |
| **引用数** | 17 |
| **HuggingFace** | gOLIVES/OLIVES_Dataset |
| **真实性** | ⭐⭐⭐ 权威(NeurIPS顶会) |

**三模态**:
- ①图片: OCT视网膜扫描图(能看到视网膜层结构/病变)
- ②时序: Scan序号(1-49,治疗时间线) + BCVA视力 + CST视网膜厚度 + 16个生物标志物
- ③文本: 疾病标签(Normal/AMD/DME/RVO)

**语义关联**: 视网膜层病变(OCT) ←→ 生物标志物异常(时序) ←→ 疾病诊断(标签)

**实验结果**: 2464条样本, 4个case检测出2条时序vs标签冲突 + 2条CLIP图片vs标签冲突

### 2. Diabetic Retinopathy Progression Africa (眼科)

| 维度 | 内容 |
|---|---|
| **HuggingFace** | macular/diabetic-retinopathy-multimodal-progression-africa |
| **图片来源** | APTOS-2019 (India) — 真实眼底照片 |
| **临床数据** | 合成EHR (基于真实分布) |
| **规模** | 532条(validation split) |
| **真实性** | ⭐⭐ 可信(图片真实, EHR合成但基于真实分布) |

**三模态**:
- ①图片: 眼底照片(能看到微血管瘤/出血/渗出)
- ②时序: HbA1c血糖(4.5-15.6) + 血压(82-190) + eGFR肾功能(5-135) + 糖尿病病程(0-37年)
- ③文本: 诊断标签(No_DR/Mild/Moderate/Severe/Proliferative_DR) + 5年进展标签

**语义关联**: 血糖控制差(HbA1c高) → 视网膜病变 → 眼底照片可见 → 诊断标签

**实验结果**: 532条样本, 6个case检测出4条时序vs标签冲突(HbA1c高但No_DR) + CLIP图片vs标签冲突

### 3. H4R/therness Welding Dataset (焊接)

| 维度 | 内容 |
|---|---|
| **HuggingFace** | H4R/therness |
| **来源** | Hackathon for Robotic Welding |
| **规模** | 820个缺陷样本 + 732个正常样本 (14925个文件) |
| **缺陷类型** | burnthrough/crater_crack/lack_of_fusion/excessive_penetration/overlap等 |
| **真实性** | ⭐⭐ 可信(真实焊接数据,但来自hackathon非正式论文) |

**三模态**:
- ①图片: 焊缝照片(2000×900, 能看到烧穿/裂纹/未熔合等缺陷)
- ②时序: 传感器CSV(压力/CO2流量/送丝速度/焊接电流/电压, 逐毫秒记录)
- ③文本: 缺陷标签(目录名: burnthrough/crater_crack/lack_of_fusion/good)

**语义关联**: 焊接参数异常(电流/电压波动) → 物理因果 → 焊缝缺陷 → 照片可见 → 标签确认

**实验结果**: 4个case(烧穿/正常/裂纹/未熔合), CLIP分析焊缝照片 + IsolationForest分析传感器时序 + 缺陷标签对比

## 三、检测方法

### 冲突检测架构

```
模态①图片 → CLIP零样本分类 → 图片识别结果
                                    ↓
模态②时序 → IsolationForest/规则 → 时序异常检测     → 跨模态冲突检测
                                    ↓                    ↓
模态③文本 → 标签解析          → 标签内容     → 对比 → 冲突报告
```

### 冲突类型

| 冲突类型 | 检测方法 | 例子 |
|---|---|---|
| 图片vs标签 | CLIP识别 vs 诊断标签 | CLIP从OCT识别AMD但标签Normal |
| 时序vs标签 | 临床规则/IsolationForest vs 标签 | HbA1c=13但标签No_DR |
| 时序vs图片 | 传感器异常 vs 图片状态 | 焊接电流异常但焊缝照片正常 |

## 五、结论

1. **找到3个已验证并跑通的三模态数据集**: OLIVES(眼科) + DR Progression(眼科) + H4R Welding(焊接)
2. **另有2个已验证待下载**: HANCOCK(病理, Nature Communications) + LADD(食品, Mendeley)
3. **所有数据集的三模态天然配套**: 图片+时序+文本来自同一个对象/患者/实验
4. **图片与时序有语义关联**: 视网膜病变←→血糖/生物标志物; 焊缝缺陷←→焊接参数
5. **冲突检测有效**: CLIP图片分析 + IsolationForest时序异常 + 规则引擎 → 检测出真实的跨模态不一致
