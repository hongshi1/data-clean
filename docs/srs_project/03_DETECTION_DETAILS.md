## 二、语义不一致检测

> 检查内容矛盾, 需要先抽取参数再比较

### 做了的

| 检测项 | 方法 | 结果 | 可信度 | 依赖知识库? |
|---|---|:---:|:---:|:---:|
| **同参数不同值** | **NLI(GLM-5判断句子对矛盾)** | **1条真矛盾** | ✅ | ❌ |
| Z3约束求解 | SMT公式→求解SAT/UNSAT | 0条(8全假阳性) | ✅ | ✅ |
| 跨文档矛盾 | 值比较 | 0条(7全不同系统) | ✅ | ✅ |
| 需求重复 | embedding相似度 | 22对 | ⚠️ | ❌ |

### 唯一真矛盾

```
文件: gamma j.pdf
句1: "Have an availability of 99.999%"  (第1.4节)
句2: "The system shall have an availability of 99.99%"  (第5.4节)

NLI判断: contradiction (置信度0.95)
  理由: 同一系统(Web Store)两种不同可用性要求

Z3判断: UNSAT
  x == 99.999 AND x == 99.99 → 不可同时满足

人工确认: 真实矛盾
```

### Z3为什么全假阳性

```
Z3的8个UNSAT全是假阳性, 原因:

1. response_time=238 → 实际是文档编号"TCS 238", 不是响应时间
2. memory_size=1472 → 实际是"MIL-STD 1472"标准号
3. duty_cycle=100 → 实际是"DutyLo := 100"变量定义
4. processing_time=500 → 实际是"500,000 items per year"
5. beep_frequency=500/700 → 实际是"alternating 500Hz and 700Hz"(交替, 非矛盾)

根因: 参数抽取(Span分类器)把非参数值误提取为参数值
→ Z3基于错误的输入做求解 → 垃圾进垃圾出
```

### NLI为什么有效

```
NLI能排除Z3无法排除的假阳性:

jitter 2.0 vs 1.0 → NLI: neutral (Phase 1 vs Phase 2, 不同阶段)
response_time 238 vs 1.0 → NLI: neutral (238是文档编号)
memory_size 50 vs 1472 → NLI: neutral (1472是MIL-STD标准号)
duty_cycle 100 vs 0 → NLI: neutral (变量初始化值)

因为NLI(GLM-5)有语义理解能力, 能区分:
- "同一参数同一系统的不同值" → contradiction(真矛盾)
- "不同阶段/不同配置/不同系统" → neutral(不是矛盾)
```

### 没做的

| 检测项 | 为什么没做 |
|---|---|
| 正文↔表格矛盾 | 需要标注每个约束的来源(正文/表格), 没做 |
| 术语不一致 | 需要实体链接模型, 没接入 |
| 跨文档(同系统)矛盾 | 需要判断文档是否同一系统, 没做 |

## 三、逻辑不一致检测

> 检查约束在逻辑上能否同时满足

### 做了的

| 检测项 | 方法 | 结果 |
|---|---|:---:|
| Z3约束求解 | SMT公式求解 | 0条真矛盾(全假阳性) |
| 时序环检测 | 正则+NetworkX | 0个环(提取太弱) |

### 没做的

| 检测项 | 为什么没做 |
|---|---|
| 物理约束(完整版) | 物理规则库只有频率×时间一条 |
| 优先级矛盾 | 没实现 |

## 四、图片-文本不一致检测

> 检查图片与文字之间的一致性

### 做了的

| 检测器 | 论文 | 检测什么 | 结果 | 依赖知识库? |
|---|---|---|:---:|:---:|
| FloCA | 2602.14035 | 流程图路径(可达/死锁/完整性) | 37个问题 | ❌ |
| Visual Entailment | 1901.06706 | 图文蕴含(文字vs图片内容) | 1个矛盾 | ❌ |
| ChartVE | 2312.10160 | 图表数值一致性 | 0个冲突 | ❌ |
| DFD规则 | 1011.0278 | 孤立节点+数据流平衡 | 4个违反 | ❌ |
| Model Checking+Z3 | — | 状态机(覆盖/可达/死锁/Z3) | 1个失败 | ❌ |

### 具体例子

```
[图文矛盾] elsfork.pdf p19:
  文字: "Figure 1 shows document structure"
  图片: 实际是"风力发电通信系统概览图"
  检测: VLM判断 → contradiction

[流程图问题] telescope.pdf p13:
  VLM提取: 7个节点, 4条边
  NetworkX分析: 节点"5 Guard Pixels"不可达 + 节点"300+5 Pixels"死锁

[状态机] tcs.pdf p19:
  状态: STARTUP→OPERATIONS→SHUTDOWN→STARTUP
  检查: completeness失败(3条边的转换条件文本未描述)
```
