```
│  │

│  (327块: text 228 + table 75 + image 24)
│
│
├─[阶段2] 结构化增强                      73.3s  ██████████████████ 54%
│  我们的工具(三个子步骤)
│  │
│  ├─ 2a. Visio图翻译              1.2s
│  │     23图 → 235节点(text/type/坐标)
│  │
│  ├─ 2b. VLM图片理解             72.0s  ← 可离线(当前已存=0s)
│  │     24张 → caption + key_elements
│  │
│  └─ 2c. 证据池构建               0.1s
│        75表+24图+235Visio节点 → 1,127个检索单元
│
│
├─[阶段3] 向量索引                        3.4s  █ 2%

│  │
│  ├─ 3a. BGE编码                  3.4s
│  │     1,127单元 → 1,127×1024维冻结向量
│  │

│        向量矩阵 + IDF权重 + owner分段
│
│
▼
输出: 可检索证据池(就绪后查询~14ms)
```
