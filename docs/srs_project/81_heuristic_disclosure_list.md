## 建议论文写法

### 方法节末尾加一段：

> 上述级联系统的判定行为涉及若干人工设定的阈值和词表。我们在开发集（45条QA，29主题簇整簇切分）上通过网格扫描标定了两个关键门控（nli_gate=0.7, llm_refute_gate=0.6），并通过消融实验验证了聚合语义（strict ∀, per-claim融合）的选择。其余阈值（如序列配对门槛0.28、主体提取窗口32字符等）沿用工程经验值，未做系统性扫描，我们在附录中完整列出。所有涉及GJB标准条款的封闭清单均在04号SRS上校准，其对跨文档泛化的影响通过06号sound集（det macro-F1=0.262, gap=-0.486）进行了量化评估。
