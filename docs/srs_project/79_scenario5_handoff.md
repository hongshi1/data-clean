## 3. 核心结论(已达成共识, 勿重新论证)

### 3.1 17项检测的比对矩阵重组(76号, 比原文三层分类更有操作性)

```
A类 QA对内部(指令vs回答)     4项: 状态术语/同名异义/阈值边界/条件缺项     ← 零图片零VLM
B类 图片 vs QA              8项: 同义异名/对象类别/行为术语/隐患属性/     ← 需感知栈
                                  属性丢失/值域/数量/判定逻辑/场景错配
C类 跨QA样本(语料级)          3项: 缩写代号/规则引用不一致/多样本结论矛盾  ← 需聚类管道
D类 QA vs 规则知识            2项: 枚举标签/判定逻辑冲突                 ← 规则驱动, 确定性最强
```

### 3.2 四个新方向(场景1体系没有的, 是方法贡献点)

完备性检查×2("该说没说": 属性丢失/条件缺项——应覆盖集−实际覆盖集的差集) + 场景错配(规则的场景适用域 vs 图片实际场景) + 跨样本矛盾(突破单实例范式)。

### 3.3 关键技术判断

- **"对象识别+图片理解"=场景5的方向A**: 图片→结构化清单{实体/状态/计数/场景/时间戳}→注册表→方向B比对——范式与场景1同构, 换的是多模态内容来源(文档解析→感知栈)。感知全是成熟CV任务(检测/动作/属性/场景识别), 不发明算法, 做"感知输出→注册表"的规范化桥
- **判定标准块=场景5的规则库**(类比GJB 120条): 每task自带的编号条款同时是①生成prompt②校验规则③负样本翻转源, 比GJB标准更结构化(条件→结论式), 可编译(条件子句→场景适用域, 结论→预期判定, 枚举→值域闭集)
- **时序元数据是免费红利**: 监控数据自带(camera, timestamp)——"相似图片"≈同摄像头近时帧, 跨样本聚类可完全绕过图像相似度计算
- **证据冻结协议的平移**: 场景5的冻结定义在VLM输出层——一图一抽, 描述文件冻结后全部检测对冻结描述做(隔离VLM非确定性)
- **判定语义需要四档**: support/refute/NIE + **可疑**(跨样本冲突/属性丢失不能单方判错, 送人工仲裁)

### 3.4 关键的坑(已识别)

- **"睡岗"检测严格说需要时序**: 判定标准写"长时间静止"——单帧只能判"趴伏", 多帧/短视频才能判"睡岗"
- 隐患等级不是原始感知, 是"实体+规则"推导结果——图片侧等级必须用判定标准块编译的规则引擎当标准, 不能拿另一个模型的输出当标准
- 三态语义错位: 任务自带0/1/2(含uncertain), 我们的S/R/NIE判定的是"QA对是否自洽", 两者要分开
- VLM成本地板+非确定性——级联经济学要重构(VLM成必经层)
