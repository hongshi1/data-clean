## 一、全量训练管线架构

```
输入(全量数据)                    可训练组件(端到端)                    输出
────────────────────────────────────────────────────────────────────────────
28127个对象(BGE冻结1024d快照)  ─┐
3771条结构化观测(五类模态)       │   [S0 预训练阶段]
27694条silver训练对              │    ├ 模板基线μ_{k,s}估计(留一文档)
846条gold锚点(L1 title-bridge)  │    └ 跨模态配对自监督(21650条链接)
91条QA冻结证据 + 17条违例候选    │         ↓
                                │   [S1 对比训练阶段]
                                │    ├ 残差投影 f: [x; λ·r] → 256d
                                │    ├ 去捷径(含ID降权0.3 + 无ID正例注入846条)
                                │    └ InfoNCE(τ=0.07) + boundary(margin=0.10)
                                │         ↓
                                │   [S2 证据级精调阶段]
                                │    ├ 类型化门控(kind_pair × scope)
                                │    ├ 证据指针头(28127块上的多标签CE)
                                │    └ NIE弃权头(证据不足时显式弃权)
                                └→  特征提取与上下文关联智能体
                                     输出: score(a,b) + evidence_refs + verdict
```

**编码器策略**：BGE-large-zh全程冻结（防止16域过拟合）。唯一解冻实验臂=T4（顶部2层LoRA，rank=8）。

## 二、各阶段训练配置

| 阶段 | 数据 | batch | 学习率 | epoch | 损失函数 | 显存 | 预估时间 |
|---|---|---|---|---|---|---|---|
| **S0 预训练** | 28127对象 + 21650跨模态链接 | 512 | 1e-4, cosine退火 | 10 | InfoNCE(τ=0.07) | 3.5GB | ~40分钟 |
| **S1 对比训练** | 27694对 + 846 gold + L2 fuzzy(θ=0.9505) | 256 | 1e-4, warmup 10% | 30, early-stop(patience=5) | 复合损失(见第三节) | 4GB | ~2小时 |

- BGE-large fp16推理：0.8GB

- 快照缓存命中时S1/S2编码开销近零（feature_snapshot_v1已有28127条1024d向量）

## 三、损失函数设计

### 总损失

```
L_total = L_InfoNCE(τ=0.07)
        + w_b · L_boundary(margin=0.10)
        + w_r · ‖λ·r‖²
        + w_e · L_evidence
        + w_abstain · L_NIE
```

### 各项定义

| 损失项 | 公式 | 作用 | 权重 |
|---|---|---|---|
| L_InfoNCE | −(1/N)Σ log[exp(sim(a,p)/τ) / Σ_j exp(sim(a,j)/τ)] | 跨模态对齐 | 1.0 |
| L_boundary | max(0, sim(a,n) + margin − sim(a,p)) | 身份边界感知 | w_b |
| L_residual | ‖λ·r‖² | 残差正则（防过拟合模板噪声） | w_r = 1e-3 |
| L_evidence | 多标签交叉熵（28127块上的证据指针） | 证据级输出 | w_e = 1.0 (仅S2) |
| L_NIE | 弃权头二分类交叉熵 | 证据不足弃权 | w_abstain = 0.5 |

### 权重确定策略

- w_b ∈ {0.25, 0.5, 1.0}——dev-only小网格搜索（当前锁定0.5，C3已证boundary是主贡献）
- 选择规则：**dev AUC ∧ false merge ≤ 0.02 双约束下取 Δ_ID 最小者**

### 去捷径数据策略

| 路径 | 具体操作 | 数据量 |
|---|---|---|
| ① 含ID正例降权 | 训练中降低权重至0.3 | 13489对 |
| ② 无ID正例注入 | L1 title-bridge(gold) + L2 fuzzy(θ=0.9505) | 846 + ~16000 |

## 四、评测协议

### 训练过程中

- 每epoch在dev上评测（缓存向量上<10秒）
- 三条监控曲线：AUC / false merge / Δ_ID
- early stopping：patience = 5

### 最终test三层

| 评测层 | 数据 | 指标 | 作用 |
|---|---|---|---|
| gold-proxy | 2991条（外生，不参与训练） | AUC + Wilson 95% CI | 绝对性能 |
| LODO-16 | 每文档留出 | 宏平均AUC + 学习曲线(8/12/15 doc) | 跨域迁移 |
| ID分层 | 含ID列 / 不含ID列 / 全集列 | 分层AUC | 捷径依赖度 |

### 证据级评测

| 指标 | 定义 | 数据 |
|---|---|---|
| AVeriTeC Score | 判定对 ∧ evidence overlap ≥ 0.5 | 108条定位gold |
| F1_loc \| verdict_correct | 条件定位率（判定≠定位的诊断量） | 同上 |
| 联合分 J | F1_verdict × F1_loc | 同上 |

### 统计检验

- 文档级paired bootstrap（10,000次重采样）
- Holm校正（6个RQ的多重比较）
- Levene检验（RQ2方差齐性）

## 五、实验矩阵（增量贡献表）

| 实验臂 | 配置 | test AUC预期 | Δ_ID预期 | 定位 |
|---|---|---|---|---|
| T0 | 仅投影头（现状A3） | 0.9193（锁定基线） | 0.2358 | 基线 |
| T1 | + 残差融合（λ∈{0.1, 0.5, 1.0}扫描） | 0.93 ± 0.01 | ~0.20 | RQ1-3 |
| T2 | T1 + 去捷径 | 0.92 - 0.94 | **≤ 0.12** | RQ4-5 |
| T3 | T2 + 门控 + 证据级（**全量主行**） | 0.93 - 0.95 | ≤ 0.12 | 主行：AVeriTeC ≥ 0.6, FM ≤ 0.015 |
| T4 | T3 + 解冻顶2层LoRA(r=8) | 报告过拟合风险 | — | 探索性（不进主表） |

### 预期提升幅度

- **含ID子集**：+0.01 ~ +0.03 AUC
- **不含ID子集**：从不可评→可评（846锚点支撑）
- **LODO方差**：Levene检验预期显著收缩
- **Δ_ID**：从0.2358压缩至≤0.12

### 诚实边界

- T3-T0差值 < 2×bootstrap CI时只报方向不报显著性
- 108条定位gold样本量限制AVeriTeC结论强度
- 16域LODO统计功效弱，只报置信区间
