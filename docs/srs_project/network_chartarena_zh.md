## 标注格式

每条含:
- `img_path`: 图表图片(可下载)
- `anno`: 结构化标注(Mermaid流程图/数据表/层级列表)
- `chart_type`: 图表类型
- `lang_type`: 中文/英文

## 标注内容类型

| anno类型 | 条数 | 说明 |
|---------|------|------|
| markdown表格 | 905 | 图表底层数据表 |
| mermaid图 | 154 | 流程图(可渲染) |
| 层级列表 | 149 | 思维导图结构 |

## 使用原则

1. **source=network**, 与16份原生(source=native)完全隔离
2. 评测时分开报告, 不混合
3. 只做泛化测试, 不参与主实验
4. 流程图154条可增强sc2(流程图+文字一致性)
