# 62 证据打分与精选研究设计：Sufficiency–Selection–Stopping统一框架

日期：2026-10-27 | 状态：设计定稿 | 位置：插在UnitFocusedRerank之后、QualityContract之前

---

## 一、核心问题

当前系统召回top-50证据后**全部送给下游**。但这50条中大量冗余、部分无关、部分已足够。科研问题是：

> **在预算约束下选出支撑下游裁决的最小充分证据集——不是"多找证据"，而是"选对证据"。**

---

## 二、统一框架（5个方向=1个决策问题的不同面）

```text
top-50 (EvidenceHit, 多头)
  → [⑤ 逐头校准 p_e + conformal集合 Cα]          ← 地基
  → [① 充分性 S(q,E)] ──不足──→ [④ 停止/义务缺口定向补召回] ↺
      │ 充分
  → [②③ 受约束选择: 义务matroid + NLI去重] → |E*|≈5-10
  → QualityContract 裁决 → 证据级评测
```

---

## 三、五个方向的具体设计

### ⑤ 证据置信度校准（P0地基——其他一切的输入）

**问题**：多头的分数尺度不同（语义单元头0-1、BM25无界、cross-encoder约10），现融合公式`r + 0.1*(base_n/rrng)*abs(rmax)`是尺度敏感的ad-hoc拼接。

**方法**：
```text
逐头保序回归（Isotonic Regression）
  → 在15个文档上校准，1个文档测试（LODO天然防泄漏）
  → 各头分数统一校准为 p_e = P(e为真证据 | 该头分数)

Split-conformal保证
  → P(真证据 ∈ C_α) ≥ 1-α
  → 分布无关的有限样本保证
```

**集成点**：直接替换`rerank.py:73`的融合公式。`p_e`是后续①②③的统一输入。

**实验**：校准前后ECE；conformal覆盖率-集合大小曲线。

**创新**：证据级conformal prediction应用于RE一致性输入选择，文献先例为零。

---

### ① 证据充分性判定（P0核心——决策变量）

**问题**：给定问题q和已召回证据集E，判定“当前证据是否足以完成裁决”。不足时应继续召回，而非硬判。

**方法**：
```text
集合函数 S(q,E) ∈ [0,1] ≈ P(下游可裁决 | q, E)

实现：义务锚定覆盖度
  QualityContract的六路证据义务 O = {o_1,...,o_6}
  S(q,E) = g( Σ_j w_j · max_{e∈E} [p_e · m(o_j, e)] )

  其中 m(o_j, e) = 证据e满足义务o_j的程度
       p_e = ⑤校准后的证据置信度
       w_j = 义务权重（可学习或领域先验）

训练方式：对Oracle证据做随机子集dropout
  → 学出单调集合函数（加入证据→S不降）
  → 避免逐条打分相加的组合误差
```

**与FEVER/SQuAD2.0的差异**：文献判“答案可回答性”（二分类），我们判“契约义务的可裁决性”（三分类：一致/不一致/证据不足），且分解为六路可解释条件。

**集成点**：`QualityHypothesis.status="insufficient"`接口已有，本设计为其提供原理化打分器。同时输出是④的停止信号。

**实验**：以证据级评测(Oracle/Partial/NoEv)为金标，报告insufficiency AUROC + 裁决F1-预算曲线。

---

### ② 冗余消除：最小充分证据集（P1）

**问题**：top-50中同一表格的不同行、同一图的不同节点大量语义重复。

**方法**：
```text
目标：E* = argmin |E'|  s.t.  V(E') ≥ V(E_50) - ε

两层去重：
  第一层（结构先验）：同owner同kind → 天然冗余
    EvidenceStore的owner分段索引直接支持
  第二层（语义判断）：本地mDeBERTa NLI
    判"单元A包含单元B的信息" → 真冗余
    同义不同值 → 不是冗余（是潜在冲突！）

选择：惰性贪心（Nemhauser次模最大化）
  每次选边际增益最大的证据加入E*
```

**关键区分**：**冗余=信息重复**，**冲突=同义不同值**。去重时保留冲突对，只去除真冗余。

**集成点**：插在UnitFocusedRerank之后。mDeBERTa本地可用。

**实验**：压缩率-下游F1的Pareto曲线；对照MMR/余弦去重/oracle最优。

**创新**：EntailmentBank在自由文本做最小证明树；我们在**结构化多模态证据**上做“结构先验×entailment”去重。

---

### ③ 多样性选择：契约约束DPP（P1，与②合并）

**问题**：选择证据时需要确保覆盖不同模态/章节/证据类型。

**方法**：
```text
目标：E* = argmax f(E)  s.t.  |E| ≤ k 且 |E ∩ P_i| ≥ b_i

其中 P_i = 模态/章节/证据类型的分区
     b_i = 各分区的最低配额

实现：Quality-Definition DPP
  L(E) = det( diag(q) · S · diag(q) )

  q = 校准后p_e（来自⑤）
  S = 相似度核（BGE相似 + 结构特征：同owner→高相似）

六路义务直接翻译为分区约束（matroid约束）
  → 契约约束DPP，带greedy 1-1/e近似保证
```

**集成点**：六路证据完备性=现成分区约束；BGE本地embedding已有。

**创新**：文献DPP做通用查询多样性；我们把**完备性契约编译为matroid约束**。

---

### ④ 自适应停止策略（P2压轴）

**问题**：什么时候停止继续召回？固定top-50是全局次优的。

**方法**：
```text
序贯决策MDP：
  状态 = (q, E_t, 检索轨迹)
  动作 = {继续召回, 停止并裁决}
  停止条件 = E[V(E_t ∪ Δ)] - V(E_t) < c

关键设计：verifier-in-the-loop
  停止信号 = 下游校验器对E_t的裁决不确定性
  （区别于FLARE/Self-RAG的生成不确定性）

不足时：按义务缺口定向补召回
  → 不是"再多召回50条"
  → 而是"缺哪一路就补哪一路"（结构化引导）
```

**集成点**：S(q,E_t)即①的输出作为停止统计量。多头轨迹MultiHeadRecall已有。

**创新**：停止信号对齐**下游校验置信度**而非生成流畅度（区别于FLARE）；“继续召回”由义务缺口结构化引导。

## 四、优先级与依赖

```text
P0（先做，一周内）：
  ⑤ 逐头校准 → 所有后续的输入
  ① 充分性判定 → 核心决策变量

P1（第二步）：
  ②③ 合并为"受约束选择"模块
  （matroid约束下次模选择统一MMR/DPP特例）

P2（压轴）：
  ④ 自适应停止（组合①+③，系统改动最大）
```

## 六、论文叙事

> **从"召回数量"到"证据质量"的范式转移。**

三个创新点均无RE领域先例：
1. **集合级决策函数**：S(q,E)判可裁决性而非可回答性
2. **契约编译约束**：六路义务→matroid分区→DPP选择
3. **分布无关保证**：conformal prediction应用于证据输入选择
