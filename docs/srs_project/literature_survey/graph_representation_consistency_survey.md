# 文档级一致性检测的图方法与表示学习方法调研报告

> 调研日期：2026-08-10
> 定位：为"GJB SRS同一ID跨位置一致性检测"补充**图方法与表示学习**方向的方法候选，与已有全景调研(`nlp4re_llm4re_comprehensive_survey.md`)和语义层路线设计(`semantic_layer_detection_roadmap.md`)互补（后两者已覆盖NLI/LLM/规则/多模态/表格NLI，本文覆盖5个图与表示方向）
> 数据基础：12种规则信号（S1-S12）、971个ID/2016次出现、137个图文表聚合条目、14条真实矛盾Gold Standard、双模型(NLI+GLM-5)验证管线
> 核查方式：关键引用经DBLP/arXiv核实（Bendík 2017出处已确认）

---

## 0. 任务重述与评估框架

**检测任务**：同一需求ID在文档不同位置（章节标题/正文/功能表/用例表/合格性表/追溯表/图片说明）的名称/属性/描述是否一致。

**评估维度**（每方向按此打分）：
1. **ID锚定契合度**：能否利用"S1需求ID"这一精确锚点（而非纯语义对）
2. **矛盾定位能力**：能否给出"哪两个位置、哪个属性、差在哪"（证据链）
3. **合理差异处理**：能否区分"设备配置梯度等合理差异"与"真实矛盾"（本项目最痛的点）
4. **中文/军事领域适配**：是否依赖英文预训练或领域标注
5. **数据需求**：我们只有14~80条gold标注，971个ID节点

## 1. 方向1：知识图谱/异构图一致性检测

### 代表论文

| 论文 | 年份/会议 | 核心方法 |
|------|-----------|----------|
| **Bendík, "Consistency checking in requirements analysis"**（DBLP已核实: ISSTA 2017, DOI 10.1145/3092703.3098239） | ISSTA 2017 | 需求依赖图+SAT求解，不可满足→矛盾+最小不可满足子集 |
| **GCN-Align** (Wang et al., "Cross-lingual Knowledge Graph Alignment via Graph Convolutional Networks") | EMNLP 2018 | GCN嵌入KG做实体对齐（"同一个事物"判定） |
| **BootEA** (Sun et al., "Bootstrapping Entity Alignment with Knowledge Graph Embedding") | IJCAI 2018 | 对齐种子自举+结构嵌入迭代扩充（对齐标注稀缺时的扩增法） |
| **ContractCheck**（本地调研已详述） | arXiv:2504.18422 | 合同条款→本体+FOL→SMT，逻辑层矛盾检测 |
| 补充经典：**Kalyanpur et al., "Debugging unsatisfiable classes in OWL ontologies"** | JWS 2006 | DL推理器定位本体中不可满足类及最小解释（KG一致性调试的奠基工作） |

### 方法原理

Bendík把需求间依赖编码为布尔约束（A requires B → A→B），SAT不可满足即存在矛盾，且可返回不可满足子集作为矛盾源——这是"图约束→形式化→矛盾定位"的完整范式。GCN-Align/BootEA证明"实体对齐"（判断两处文本是否指同一实体）可建模为嵌入空间的结构对齐任务，BootEA的自举策略解决对齐标注稀缺问题。本体调试（Kalyanpur 2006）给出"约束违反+最小解释集"的知识图谱一致性检查模板，ContractCheck 2025将其迁移到合同文本。

### 对GJB SRS的适用性评估：**强**

- 我们的12种信号（ID/章节/标题/表格/图片/追溯/接口/版本/异常流/类型/位置）**天然就是异构图**：ID节点、名称节点、位置节点、表节点、图节点、版本节点+出现/命名/包含/追溯/版本边——图构建几乎零成本
- ID锚定把"实体对齐"降维为"已知同实体，比对属性值"，绕开了实体对齐最难的环节（GCN-Align/BootEA解决的对齐问题我们已由ID解决）
- 图约束（同ID唯一名称、同软件唯一版本、追溯两端名称一致）直接命中Gold Standard中的12条同ID多名+2条版本矛盾
- Bendík 2017证明该范式在RE领域可行；缺点（需人工形式化）由我们的12种结构化信号大幅缓解

### 科研创新空间

- **ID锚定的"属性级"一致性图**：现有KG一致性检查做实体/类级别，无人做"同一实体跨文档位置的属性值一致性"——把ID作为超级锚点的属性约束图是本项目可定义的新问题
- **图约束+LLM混合的矛盾定位**：图约束给出候选，LLM/双模型只验证候选——"结构化证据+语义验证"的混合范式在KG一致性领域尚未成形
- **跨文档图**：16份SRS共享PZXQ ID（10个共享ID），构建跨文档一致性图是现成的新场景（TLR文献做req↔code，无人做req↔req跨文档）

## 2. 方向2：图神经网络(GNN)用于实体/关系一致性

### 代表论文

| 论文 | 年份/会议 | 核心方法 |
|------|-----------|----------|
| **GAT** (Veličković et al., "Graph Attention Networks") | ICLR 2018 | 注意力聚合邻居特征做节点分类 |
| **RGCN** (Schlichtkrull et al., "Modeling Relational Data with Graph Convolutional Networks") | ESWC 2018 | 关系类型感知的GCN，KG链接预测/节点分类 |
| **GEAR** (Zhou et al., "Graph-based Evidence Aggregating and Reasoning for Fact Verification") | ACL 2020 | 事实核查：claim+证据句建图→GAT聚合→一致性判定（**与"文档证据→矛盾判定"最接近的任务类比**） |
| **ZeroER** (Wu et al., "Entity Resolution using Zero Labeled Examples") | KDD 2020 | 零标注实体匹配（属性特征+图结构一致性） |
| **Ditto** (Li et al., "Deep Entity Matching with Pre-trained Language Models") | VLDB 2021 | Transformer实体匹配（非GNN，作为表示层对照） |
| 补充：**DocRED** (Yao et al., ACL 2019) / **SSAN** (Xu et al., ACL 2021) | ACL 2019/2021 | 文档级关系抽取的图/结构化方法（证明"文档内部跨句关系"可建模为图） |

### 方法原理

GAT/RGCN学习"邻居信息如何决定节点标签"：把每条出现当作节点，其名称、位置类型、所在表格/图片作为特征，模型学习"哪些邻居证据预示不一致"。GEAR与我们的任务结构最像：claim+证据图→图聚合→entailed/refuted判定。ZeroER证明无需标注也能用图结构约束（同实体在不同记录中的属性应自洽）完成实体匹配。

### 对GJB SRS的适用性评估：**中**

- **不支持**：GNN需要成规模的训练数据（我们的gold仅14~80条，971节点对小图而言也偏小），且端到端GNN是黑盒，无法产出审稿人要求的位置证据链
- **支持**：我们的图结构（异构图、ID锚定、12种边类型）恰是RGCN/HAN的输入格式；GNN可做**候选矛盾对的排序器**（替代/增强NLI预筛选），或做**跨文档迁移**（16份文档留出验证集）
- GEAR类"证据聚合分类"可作为"聚合条目内部是否自洽"的端到端baseline

### 科研创新空间

- **结构信号蒸馏GNN**：用双模型(LLM/NLI)在少量标注上的判断蒸馏出"结构到矛盾"的可学习映射——把图约束的可解释性和GNN的泛化结合，是neuro-symbolic的新角度
- **可解释GNN**（GNNExplainer类）输出"矛盾证据子图"，直接对接证据链需求
- 现有矛盾检测竞品（TSRCDF-SS等）全部是文本句对方法，**无人把SRS结构建成异构图跑GNN**——即使作为消融项也有发表价值

## 3. 方向3：对比学习/表示学习

### 代表论文

| 论文 | 年份/会议 | 核心方法 |
|------|-----------|----------|
| **SimCSE** (Gao et al., "SimCSE: Simple Contrastive Learning of Sentence Embeddings") | EMNLP 2021 | dropout扰动构造正例的无监督对比学习；有监督版用NLI蕴含/矛盾对 |
| **Sentence-BERT** (Reimers & Gurevych) | EMNLP 2019 | 孪生网络+SNLI/MNLI训练，句对相似度（本地竞品TSRCDF-SS的骨干） |
| **ConSERT** (Zhang et al., ACL 2021) | ACL 2021 | 对抗扰动+对比迁移，NLI辅助监督的句子表示 |
| **Mirror-BERT** (Liu et al., "Self-Alignment Pretraining for Contrastive Representation Learning") | Findings EMNLP 2021 | 用NLI数据自对齐：entailment=正例、contradiction=负例（**"矛盾是负样本"的直接编码**） |
| **E5** (Wang et al., "Text Embeddings by Weakly-Supervised Contrastive Pre-training") | 2022 | 大规模弱监督对比预训练，通用检索嵌入 |
| **C-Pack/BGE** (Xiao et al., "C-Pack: Packaged Resources To Advance General Chinese Embedding") | SIGIR 2024 | **中文**对比嵌入与评测（BGE/M3E类），中文事实核查数据集C3NLI |

### 方法原理

对比学习的核心是把"语义等价"压进嵌入空间：相同语义→近邻，矛盾→远距。Mirror-BERT把NLI的三分类直接变成对比学习信号——**"矛盾对"可以天然作为负样本训练一致性判别嵌入**。SimCSE类模型训练后，用余弦相似度+阈值即可做"名称是否一致"的初判；C-Pack提供中文领域的现成嵌入与NLI评测。

### 对GJB SRS的适用性评估：**中**（名称层强、数值层弱）

- **强项**：名称一致性判断（"界面配置保存" vs "资源占用监控"）、截断/错字（"统算"vs"通算"，嵌入近+编辑距离小）、同义等价（"初始化"vs"配置"）——这些正是14条gold的主要类型
- **弱项**：嵌入相似度**无法判断属性值矛盾**（"达梦V7.6"vs"V7.2"嵌入距离很小却真矛盾）；阈值是玄学，可解释性差
- **独特机会**：我们有"同ID同名=正例、同ID异名=负例"的**自监督三元组**——不需要人工标注即可用SimCSE范式训练"GJB名称一致性嵌入"，这是竞品（TSRCDF-SS用通用SBERT+SimCSE）没有的领域内对比信号

### 科研创新空间

- **ID感知的对比学习**：把ID作为锚定token注入嵌入（"该名称属于ID X"），学"同ID下的名称一致性"而非通用语义相似——RE领域无人做过ID条件化的表示学习
- **用12信号构造对比数据集**：S3(标题)×S12(位置类型)的组合天然产生正/负/难负样本（同ID异名=难负例，不同ID同名=难负例），可自监督训练、开源
- **嵌入+双模型的裁判架构**：嵌入筛候选（召回）、NLI/LLM判定（精度）——把TSRCDF-SS的"嵌入分类器"升级为"嵌入+验证器"两级架构

## 4. 方向4：概率图模型（MLN/贝叶斯/PSL）

### 代表论文

| 论文 | 年份/会议 | 核心方法 |
|------|-----------|----------|
| **Markov Logic Networks** (Richardson & Domingos, "Markov logic networks") | Machine Learning 2006 | 一阶逻辑规则+权重，软约束推理（MLN奠基） |
| **Singla & Domingos, "Entity Resolution with Markov Logic"** | ICDM 2006 | MLN做实体解析：同实体属性应一致的软约束+合并决策 |
| **PSL** (Bach et al., "Hinge-Loss Markov Random Fields and Probabilistic Soft Logic") | JMLR 2017 | 连续值软逻辑（可微、可优化、比MLN快几个数量级），支持加权规则+证据 |
| **Tuffy** (Niu et al., "Tuffy: Scaling up statistical inference in Markov logic networks using an RDBMS") | VLDB 2011 | 数据库加速MLN推理（大规模图的可行性） |
| 补充：**Sundaram et al., "Assessing traceability of software engineering artifacts"** | REJ 2010 | 贝叶斯网络做需求追溯（RE领域概率图的先例） |

### 方法原理

MLN给每条一阶逻辑规则配权重：权重高=强约束（违反代价大），权重低=软约束（可违反但受罚），推理输出"世界最可能满足规则的赋值"。PSL把逻辑真值放松为[0,1]连续值，规则变成凸目标函数，可用梯度优化——特别适合"多个软证据投票判定矛盾概率"。Singla & Domingos证明MLN做实体解析的关键是**"同一实体属性一致性"的软规则族**——与我们的"同ID属性一致"约束在数学上同构。

### 对GJB SRS的适用性评估：**中**（合理差异层强、中文证据层弱）

- **强项（独特）**："合理差异 vs 真实矛盾"正是软约束问题——"同位置必须一致（高权重）"vs"跨位置可能合理差异（低权重+条件规则）"可以显式编码。这是所有确定性方法（图约束/SAT/NLI）都处理不了、而**学术界又无人讨论**的空白（本地全景调研§5.4已确认"合理差异"无文献）
- **强项**：GJB 120条规则天然是加权规则候选；双模型(NLI+LLM)的判断置信度可直接作为PSL的软证据输入
- **弱项**：MLN的规则需要结构化原子（谓词），中文文本语义证据必须由外部模型（嵌入/NLI）先转成原子置信度，端到端复杂；权重学习需要标注（我们有14条gold，可做弱监督初始化）

### 科研创新空间

- **首次用PSL建模"合理差异vs真矛盾"**：定义"差异的合理性"为条件软规则（设备形态梯度/场景差异降权，同条件异值高权重），输出"矛盾概率+被激活的规则"——这是新形式化
- **双模型置信度融合**：把LLM/NLI的判断分数作为PSL证据原子，让概率层做最终裁决（而非简单的投票/交叉验证）
- **120条GJB规则→加权规则库**：从"硬规则引擎"升级为"软规则推理"，规则质量可评测（违反强度分布）

## 5. 方向5：传递闭包/图算法（最小矛盾子图）

### 代表论文

| 论文 | 年份/会议 | 核心方法 |
|------|-----------|----------|
| **QUICKXPLAIN** (Junker, "QUICKXPLAIN: Preferred Explanations and Relaxations for Over-Constrained Problems") | AAAI 2004 | 分治搜索计算**最小冲突集(MCS)**：给矛盾约束集，返回"最小的不可满足子集" |
| **Reiter, "A theory of diagnosis from first principles"** | Artificial Intelligence 1987 | 模型诊断奠基：矛盾→最小命中集(HS-tree)枚举诊断假设 |
| **CAMUS** (Liffiton & Sakallah, "Recursive Model Sampling for Minimal Unsatisfiable Subsets") | SAT 2008 | 递归模型采样枚举**全部最小不可满足子集(MUS)** |

### 方法原理

当一组约束不可满足时，QUICKXPLAIN用分治快速找出"删掉任何一个就恢复可满足"的最小冲突集——即**最小矛盾子图**（哪几个位置+哪几条约束构成矛盾的最小证据）。Reiter的诊断框架把"矛盾解释"转化为求候选集合的最小命中集，CAMUS给出全部MUS。配合传递闭包/可达性：版本约束（V7.6 vs V7.2）、追溯链（A→B→C名称不一致）、数值约束（≥4 vs ≥40）的矛盾会沿图传播，闭包运算可先剪枝再求MUS。

### 对GJB SRS的适用性评估：**强**

- 我们的约束（同ID唯一名称、同软件唯一版本、追溯一致、表文一致）是**确定性布尔约束**，正是MCS/MUS算法的输入格式——可解释性完美（输出=证据链）
- 矛盾规模小（候选对~100以内），QUICKXPLAIN/CAMUS毫秒级完成
- 传递闭包可系统性发现"间接矛盾"（追溯链上A=B但C≠A这类需要传递推理的矛盾），这是NLI/LLM不会做、图约束+闭包天然完成的
- 与Z3/MaxSAT同族：加权版本（weighted MaxSAT）可直接实现"最小加权修正集"→把"合理差异"建模为低惩罚约束

### 科研创新空间

- **加权矛盾子图**：给约束按信号强度加权（S3标题=高权，S12位置类型=中权，跨文档=低权），输出"最小加权矛盾子图"——首次把"合理差异"做成图算法层面的惩罚权重，而非事后过滤
- **矛盾子图+LLM解释生成**：MCS给出结构化证据（位置对+约束名），LLM把证据翻译成自然语言解释——"符号定位+生成解释"正是FormalJudge/VeriTrans混合趋势在语义层的落地
- **矛盾传播闭包**：定义"名称不一致沿追溯边传播"的闭包运算，检测间接矛盾——现有RE文献无此定义

## 7. 结合资源（12信号/971 ID/双模型验证）的推荐组合

### 推荐组合A（主推）：ID锚定异构图 + 加权约束 + 最小矛盾子图（方向1+5）

```
Stage1 建图:   12信号 → ID-名称-位置-表-图-版本异构图（971 ID / 1444节 / 1207表 / 381图 / 1022追溯边）
Stage2 约束:   同ID唯一名称 · 同软件唯一版本 · 追溯链名称闭包一致 · 表文值一致 · 异常流引用存在性
Stage3 加权:   约束按信号强度加权（S3标题/S8版本=高权；跨模态/跨文档=中权；合理差异条件=降权）
Stage4 定位:   QUICKXPLAIN/CAMUS求最小加权矛盾子图 → 输出(位置对, 约束名, 证据) 结构
Stage5 验证:   双模型(NLI+GLM-5)只对MCS候选做语义验证（同ID异名是否语义等价）→ 证据链
```

- **为什么主推**：精度与可解释性由确定性图算法保证（对应"12种规则信号"的定位），LLM只做语义等价兜底（对应"双模型验证"），把2M候选压到~100个MCS候选再调LLM，成本低且每步可追溯
- 与本地既有路线（`semantic_layer_detection_roadmap.md` Stage 0-5）**兼容且升级**：把其"图约束候选+NLI判定"升级为"加权MCS+双模型验证"，补充了传递闭包和矛盾子图算法

### 推荐组合B：PSL软规则层（方向4）——"合理差异vs真矛盾"的概率化

```
把120条GJB规则+一致性约束转成PSL加权规则
证据原子 = 12信号的图约束违反强度 + 双模型判断置信度
推理输出 = 每对位置的一致/矛盾概率 + 被激活的规则
权重初始化 = 14条gold弱监督 + 人工设置"合理差异"降权条件
```

- **为什么选它**：这是唯一能显式建模"合理差异"（学术界空白，本地调研§5.4确认）的方向；与组合A构成"确定性初筛+概率层裁决"双保险——矛盾判定分歧时以加权规则裁决
- 风险：需把中文文本证据转成谓词置信度（依赖嵌入/NLI特征函数），实施上放在组合A稳定之后作为第二篇论文/增强模块

### 推荐组合C：对比学习嵌入层（方向3）——召回与名称等价判断器

```
自监督三元组:  同ID同名=正例 · 同ID异名=负例 · 不同ID同名=难负例
（S3标题×S12位置类型×S1 ID 自动构造，零人工标注）
模型: SimCSE/E5(BGE) 微调 → GJB名称一致性嵌入
用途: ① 名称等价/截断错字候选的相似度初筛（补充MCS覆盖不到的情形）
      ② 作为方向2 GNN节点的初始特征（远期）
```

- **为什么选它**：解决MCS覆盖不到的"语义等价名称"（图约束只认字符串不等，嵌入判语义等价）；自监督特性与"14条gold太少的现实"完全匹配；中文用C-Pack/BGE现成资源
- **方向2(GNN)定位**：作为远期消融——在组合C嵌入上做GAT节点分类，量化"图结构信息增益"，不进入主管线（数据量不足+可解释性差）

### 组合总览与分工

```
组合A(方向1+5) ── 确定性: 精度+证据链+最小矛盾子图（主判断）
组合B(方向4)  ── 概率性: 合理差异+双模型置信度融合（裁决层）
组合C(方向3)  ── 表示性: 语义等价+召回增强（特征层）
                    ↓
            双模型(NLI+GLM-5) 最终验证 + 解释生成
```

### 创新点定位（对论文的贡献）

1. **新任务粒度**：首个"ID锚定、跨位置、属性级"的SRS一致性检测（延续本地调研的文档级空白论证）
2. **新方法组合**：图约束MCS(确定性) + PSL软约束(概率) + 领域对比嵌入(表示) 的三层混合——现有竞品（TSRCDF-SS句对嵌入、ContractCheck纯SMT、LegalWiz纯NLI+LLM）均无此组合
3. **新形式化**：加权矛盾子图+PSL规则首度显式建模"合理差异vs真实矛盾"
4. **新数据资产**：971个ID/2016出现的真实GJB一致性图（首个中文军事SRS结构化图资产，可开源子集）

## 8. 风险提示

| 风险 | 应对 |
|------|------|
| 971节点图规模小，GNN无法发挥作用 | GNN仅做消融/远期；主管线用图算法（无需训练） |
| PSL权重学习缺标注 | 14条gold弱监督初始化+人工合理差异降权条件+事后校准 |
| 嵌入对数值矛盾(V7.6 vs V7.2)失灵 | 数值/版本类走图约束+规则（组合A），不依赖嵌入 |
| 中文NLI在军事术语上退化 | 组合C提供领域嵌入特征；双模型分歧以图约束为准 |
| QUICKXPLAIN/CAMUS实现成本 | 用Z3的unsat core提取（现成API）即可获得最小子集近似，无需自实现 |
