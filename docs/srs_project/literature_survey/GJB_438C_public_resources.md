## 六、国际对标标准（MEDIUM 相关性，论文 Related Work 必备）

### 28. IEEE 830 / ISO/IEC/IEEE 29148（SRS 国际标准）
- **资源名称**: 
  - IEEE Std 830-1998 Recommended Practice for Software Requirements Specifications（已被替代）
  - ISO/IEC/IEEE 29148:2018 Systems and software engineering — Life cycle processes — Requirements engineering（现行）
- **URL**: 
  - Wikipedia 概述: https://en.wikipedia.org/wiki/Software_requirements_specification
  - IEEE 830-1998 标准: https://standards.ieee.org/ieee/830/1222/
  - ISO 29148:2018: https://www.iso.org/standard/72089.html
  - GitHub SRS 模板: https://github.com/rick4470/IEEE-SRS-Tempate
- **资源类型**: 国际标准
- **是否包含实际文档示例**: 是（29148 附录含 SRS 结构示例；GitHub 模板含完整范例）
- **是否可公开获取**: IEEE/ISO 标准付费；Wikipedia 与 GitHub 模板免费
- **相关性**: **MEDIUM** — GJB 438C 的 SRS 结构与 IEEE 830/29148 同源（GJB 体系参考 IEEE），论文 Related Work 与"中外标准对比"章节必备
- **关键信息**:
  - IEEE 830 于 1984 年首次发布，1998 年修订，2011 年被 ISO/IEC/IEEE 29148 取代
  - 29148 现行版为 2018，覆盖需求质量准则、需求管理过程、BRS/StRS/SRS
  - SRS 推荐结构：Purpose / Overall Description / Specific Requirements（含功能、性能、接口、数据库、质量属性）
  - "Requirements Smell"概念（Femmer et al. 2017, JSS）可用于本项目的需求异味检测
