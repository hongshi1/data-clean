# QLoRA微调质量提升方案
## ——基于文献调研的系统化改进路线

> 2026-09-29 | 依据30+篇文献核验 + 项目内8份文档

---

## 核心诊断

**F1=1.000不是成果而是诊断信号**（Gururangan/Gudibande/HANS一脉的共识）。

三个已实证的质量风险：

| 风险 | 实证证据 | 文献对应 |
|---|---|---|
| 模板泄漏 | 训练/测试声明模板重叠72% | Gururangan 2018: 生成协议本身携带标签线索 |
| 构造偏差 | 合成87-94% vs 真实62.5%（虚高30pp） | Gudibande 2023: 模仿模型学到风格而非能力 |
| 真实数据缺测 | 银标0条进入训练/测试 | WILDS: ID/OOD必须分开报告 |

---

## 改进方案（按优先级）

### P0-1: 换验证集（0.5天，最高优先级）

**问题**：当前用构造真值做early stopping→选中的是最会记忆变异模式的checkpoint

**方案**：验证集换为银标高置信子集（664条中双LLM一致的362条）

```python
# 当前(有问题)
dev = [it for it in items if it['split'] == 'dev']  # 构造真值

# 修复后
dev = [it for it in silver if 双LLM一致]  # 银标高置信
```

**依据**：Gururangan 2018 (arXiv:1803.02324) — 验证集选择决定模型优化方向

### P0-2: 模板池硬分离（1-2天）

**问题**：72%的声明模板在训练/测试中共现

**方案**：为48种变异算子建立两个不相交的表面形式库

```
训练模板池:
  "功能表规定，共{N}项条目，包括：{items}，除此之外没有其他条目。"

测试模板池(同一语义的5种不同表述):
  "该表格列出了{N}项功能：{items}，此为全部清单。"
  "表格中的功能数量为{N}个：{items}，无遗漏。"
  "本表完整列举{N}项：{items}，不包含其他内容。"
  ...
```

**依据**：T0/FLAN证明多措辞prompt是zero-shot泛化的第一驱动

### P0-3: 人工金标进入主表（1天）

**问题**：当前主表只有构造F1=1.000，没有真实数据评测

**方案**：用已有的86条三方融合金标+100条双标注任务

```
| 方法 | 构造F1 | 银标F1 | 人工金标F1 |
|---|---|---|---|
| 零样本 | ~0.70 | ~0.55 | ?  ← 待测 |
| QLoRA | 1.000 | ? | ?  ← 待测 |
```

**依据**：Alternative Annotator Test (ACL 2025) — 50-100条人工子集是标准评测

### P1-1: 反事实同模板对照（1天）

**问题**：同一模板只产生inconsistent标签→模板本身携带标签先验

**方案**：每种模板构造标签平衡的三元组

```
(P0原声明, H0原声明, consistent)  ← 同模板的对照正例
(P1变异声明, H1原声明, inconsistent)  ← 同模板的负例
(P2语义保持改写, H2改写, consistent)  ← 同模板的正例
```

**依据**：Kaushik et al. 2020 (ICLR) — 合并训练后对spurious特征不敏感

### P1-2: HANS式原子诊断（1-2天）

**方案**：把闭世界模板拆成原子扰动维度，测模型对每个维度的敏感度

```
维度1: 计数变化(共3项→共2项) → 模型是否敏感?
维度2: 成员替换(A→B) → 模型是否敏感?
维度3: 语序调换 → 模型是否敏感?
维度4: 单位变化(ms→秒) → 模型是否敏感?
```

**产出**：敏感度矩阵=论文的"模型学了什么"诊断实验

### P1-3: 三源混合训练（2天）

**方案**：不只训练变异数据，混合三种来源

```
训练数据 = 原始中文NLI(防遗忘) + 变异构造(领域知识) + 银标(真实信号)
           40%                        40%                 20%
```

**依据**：ANLI的多源课程训练在所有NLI基准上SOTA

### P1-4: TAPT域适应预训练（1天）

**方案**：用16份SRS的markdown原文先做MLM继续预训练，再QLoRA

```
Step1: TAPT(16份SRS, Masked LM, 1-2 epoch) → 域适应基座
Step2: QLoRA(变异+银标混合) → 检测模型
```

**依据**：Gururangan 2020 "Don't Stop Pretraining" — 最便宜的域适应

### P2: Noisy Student迭代（1-2周）

**方案**：QLoRA-v1伪标注→分歧采样→人工确认→训练QLoRA-v2

```
QLoRA-v1 → 对全部真实pair推理 → 伪标注
  → 双模型分歧样本 → 人工仲裁(每类≥20条)
  → 确认标签+银标合并 → QLoRA-v2(带dropout噪声)
```

**依据**：Xie 2020 Noisy Student — student可超越teacher质量上限

## 预期改进效果

| 改进 | 构造F1 | 真实F1(预估) | 依据 |
|---|---|---|---|
| 当前(P0前) | 1.000 | ~62%(零样本水平) | 未在真实上测 |
| +P0换验证集 | ~0.95↓ | ~65-70%↑ | 早停不再选记忆模式 |
| +P0模板分离 | ~0.85↓ | ~70-75%↑ | 消除模板泄漏 |
| +P1反事实对照 | ~0.80↓ | ~75-80%↑ | 对spurious不敏感 |
| +P1三源混合 | ~0.85 | ~80-85%↑ | ANLI多源证据 |
| +P1 TAPT | ~0.90 | ~85-90%↑ | 域适应0.5-2pp+军事术语修复 |
| +P2 Noisy Student | ? | ~90%+↑ | 超越银标上限 |

**关键认知**：构造F1会从1.000**下降**——这是健康信号，说明原来确有泄漏。真实F1上升才是有意义的改进。

## 论文叙事转变

**旧叙事（有风险）**：
> "我们的QLoRA微调达到F1=1.000"
> → 审稿人会问：构造数据？测试集独立吗？真实数据上呢？

**新叙事（有深度）**：
> "我们诊断了合成评测的系统性虚高（模板重叠72%→拆解为零；构造vs真实差距30pp→量化），通过反事实对照+三源混合+TAPT域适应的系统化改进，在文档级零重叠的人工金标上达到F1=X。"
> → 贡献不在数字而在诊断方法+改进路线
