## 一、一句话方法

**把SRS一致性校验形式化为信道译码问题：分歧 = 不一致 ⊕ 感知噪声（D = η ⊕ ε），用文档内嵌的born-digital源（Visio XML）免费校准感知噪声分布ε，从而把每个观测到的分歧解码为"提取误差 vs 文档真实不一致"的后验概率——带可证明的分离条件、指数误差衰减界和弃权保证。**

```
观测: 通道提取的图结构 vs 表格/正文编译的结构 → 分歧D
未知: D = η ⊕ ε   (η=文档不一致[检测目标], ε=感知误差[噪声])
锚点: Visio XML → ε的分布免费可测（356图，感知层金标准）
先验: 变异引擎 → η的签名分布Σ_mut
解码: q_δ = P(η=1|D) 后验 → 阈值判决 + 弃权带
```

**为什么这不是方法堆叠**：VLM/OCR/YOLO这些通道全部降级为**可替换的测量仪器**（方法不依赖任何特定通道，通道换掉方法照跑）。方法本体是：两层潜在模型 + 译码公式 + 锚点校准协议 + 归属解码 + 三个可证命题。这就像通信系统的方法贡献是译码算法，不是天线型号。

## 二、方法的四个支柱（每个都有novelty检查背书）

### 支柱1：两层潜在模型（概念核心，堵死循环论证）

```
感知层: 图片内容 X_I --通道--> 提取结果 X̂_c        (误差ε, 锚点可校准)
文档层: 图片内容 X_I --作者--> 表格/正文 X_T        (不一致η, 检测目标)
```

**关键洞察**：锚点只校准感知层；检测假设在文档层——两层在模型上解耦。
- 通道vs通道的分歧**逻辑上不可能**是文档不一致的证据（看的是同一张图）→ 它的正确角色是融合权重、迁移诊断、难度探针
- 原始候选思想把两层混在一起会导致"用文档自身分歧校准通道、再用通道判分歧"的循环论证——这是对抗性审查发现的致命结构，此分层堵死它

### 支柱2：锚点校准协议（资源+机制，撞车检查零命中）

Visio XML解析在arXiv**零命中**；born-digital当GT有先例（ChemScraper用PDF原语），但**用于多通道误差模型校准**无先例。

```
离线校准（算法1）:
  356锚点图 → 通道提取vs金标准 → 元素级误差标注(10^3~10^4条)
  → GLMM拟合: p_c(φ) = σ(α + β·φ + u_doc)   [φ=字高/密度/交叉数等可观测难度特征]
  → 融合器端到端校准: p_F = P(F(X̂_1..k) ≠ X_I)  [相关性被整体吸收,不做因子化]
  → 变异签名: Σ_mut = 8类算子的分歧指纹
  → 共形阈值: (τ⁺,τ⁻)由Learn-then-Test选出, FDR≤α有限样本保证

在线检测（算法2）:
  每实体: Agg聚合{图,表,正文} → 编译X_T → 通道提取X̂_F
  → 归一化N(良性变异商掉) → 类型化分歧Δ(带归属图)
  → 节点潜在状态MRF归属解码 → q_δ后验
  → q>τ⁺报告(带证据链) / q<τ⁻通过 / 否则弃权送人工
```

**锚点三分协议**（防泄漏，对抗审查FATAL#4的解法）：文档级分块切分为C3训练池/校准池/评测池，75条真实不一致**只进评测永不进训练**。

### 支柱3：归属解码（星型混淆的结构化解，本项目原创）

**问题**：节点对齐错误污染其上挂接的所有边比较 → "节点缺失"型真实不一致与"节点错配"型感知错误产生**几乎相同的星型分歧形态**。

**星型噪声底定理**：度数k的节点的全部k条邻接边在H₀下同时分歧的概率 ≈ p_mm（节点错配率），而非朴素独立的 p_e^k。

**解法**：节点潜在状态MRF {correct/mis-matched/spurious/missed}，边分歧条件于节点状态 → 每个分歧簇输出对每个候选成因的后验归属——**证据链的天然内容**（类比软件测试的基于谱的错误定位）。

### 支柱4：Provenance Drift（真实正例的免费来源，杀死"自造bug"指控）

**对抗审查FATAL#1的正面解法**：嵌入源与渲染内容之间的diff**本身定义一类真实不一致**：

> Visio XML源里接口已改至100G，但正文表格仍是10G → 意图-呈现漂移

这类bug是文档演化的真实产物（作者改了源忘了改渲染/正文），**天然免疫"你在自造bug上测检测器"的质疑**，且撞车检查确认无人系统研究过（"single sourcing"技术传播文献需投稿前复核）。据我们已提取的356个Visio结构，可以直接跑一遍源-vs-渲染/正文的diff，**第一批真实正例免费到手**。

## 三、理论（三个可证命题，简化模型下已证明）

| 命题 | 内容 | 论文角色 |
|------|------|---------|
| **P1 分离条件** | MAP规则"见分歧即报不一致"贝叶斯一致 ⟺ π > p。推论1.1：**不知道p连分歧的方向性解释都不可能**（p<1/2时分歧是不一致证据，p>1/2时反过来）→ 锚点校准是先决条件不是装饰 | 论证校准必要性 |
| **P2 指数分离** | 触及m个元素的不一致，检测错误率 ≤ exp(-m·C(p))，C(p)=-½log(4p(1-p))。推论2.1块修正：指数按**独立失败成因数**B计（级联+相关性统一处理） | 能力边界声明（honest scoping） |
| **P3 弃权支配** | 带弃权检测器在风险-覆盖前沿上逐点支配强制分类；共形阈值给FDR≤α的分布自由保证 | 弃权机制的理论依据 |

**数值示例（讲清整个故事）**：π=0.05，单通道p=0.1时，单条分歧后验仅0.32（大概率是噪声）；但3元素簇（异常流删除签名）后验=0.97。**单元素不一致靠融合压噪声，簇不一致靠指数积累——两类检测策略在方法内自动分化。**

**优雅退化**：分布漂移下（p'→1/2且模型如实更新），后验退化为先验→检测器**自动弃权而非自信报错**。失效模式是"沉默地不工作"（弃权率上升），不是"自信地出错"。

## 四、撞车防御（投稿前必须做的显式划界）

**最脆弱指控**："ACDD = Dawid-Skene(加完美标注者) + PI-explains-away-label-noise(2202.09244) + selective prediction"——审稿人一段话可拼装。

**防御表（写进论文）**：

| 对比项 | DS/PWS | PI-noise线 | **ACDD** |
|--------|--------|-----------|----------|
| 误差结构 | 标量混淆矩阵 | 特征级标签去噪 | **元素类型/几何/难度条件化的结构化误差模型** |
| 目标 | 标签聚合 | 干净标签 | **因果归因：误差vs真值后验** |
| 特权可用性 | 全域均匀 | 训练时全量 | **部分特权+anchored→unanchored协变量偏移（anchor masking协议显式检验）** |
| 输出 | 众数标签 | 去噪标签 | **后验+证据链+弃权** |

**LUPI判定**（撞车检查结论）：严格不成立（部分特权+锚点是标签源非特征）。理论挂靠改用**广义蒸馏(López-Paz 2016) + 测量误差修正(生物统计2607.25868线) + selective prediction**三层叙事。

**命名**：方法名ACDD保留（HarmTrace的"Anchor-Calibrated"是纯术语撞车，不同域）；注意避开。

## 五、评测设计（反循环是第一原则）

### 主评测：三层证据

1. **Provenance drift真实正例**（新）：源-vs-渲染/正文diff，第一批免费真实bug
2. **75条人工裁决真实不一致**（双人独立+κ；只进评测永不进训练）
3. **变异引擎**（降级为augmentation+压力测试仪器）：反循环协议——Σ_mut先验只用算子子集{id/name/value}，评测在其余算子+真实75条上

### 必备基线（对抗审查FATAL#3，无退路）

| 基线 | 检验什么 |
|------|---------|
| B1 裸VLM端到端（≥2个模型家族）| 前沿VLM直接判断的上限——**2026年这是强制基线** |
| B2 未校准多数投票 | 校准的增益 |
| B3 规则检测器（语法层）| 语法层之外的增益 |
| B4 无锚一致性检测(Platanios式) | **锚点资源的价值** |
| B5 单通道校准 | 融合的增益 |
| 人类专家上限（样本上）| ceiling |

### 头牌指标

- **校准性能：可靠性图+ECE**（"后验有概率语义"是核心卖点，ECE显著优于B1/B2是核心证据）
- 风险-覆盖曲线（实测vs P3预测前沿形状）
- AUROC/AUPRC + 按变异类型召回（Wilson区间）
- 真实75条：precision@k + 双人κ（不做召回声明——无完备金标准）

### 消融矩阵（8项）

A-1无校准 / A-2无收缩 / A-3因子化融合 / A-4无归属MRF / A-5强制分类 / A-6无迁移诊断 / A-7无变异先验 / A-8无规范化N

### 与方向A的干净边界

```
Recall_sys = P(Agg找齐视图对)[方向A] × P(检出|找齐)[ACDD]
```
- ACDD评测**条件化于聚合正确**（oracle聚合或人工核对视图对）
- Agg输出匹配置信度→ACDD门控比较（低置信弃权）——两方向唯一接口，松耦合
- 方向A可独立发表，ACDD把第二因子做到有理论保证

## 六、诚实的脆弱点（9条，写进论文limitation）

1. **π > p可能不成立**（最高风险）：困难图边级p可达0.3-0.4而π天然小→单元素签名类型退化为"只能弃权"，方法从检测器收缩为分诊器。**声明按签名类型分层，不做总体声明**
2. 锚点选择偏差+通道共享盲区（一致地错）：φ空间支持性检查+人工抽查弃权样本，残余风险不可消除只能诚实报告
3. 变异先验代表性：真实错误更微妙更稀疏；敏感性分析+真实75条校准检查
4. 文本编译器κ_T非零误差（"主事件流→图"有解释空间）：p_κ进L₀，粒度不一致分歧默认弃权
5. 锚点有效性X_I^vis=X_I假设：渲染一致性抽查，不同步率>2%剔除
6. 良性变异边界N不完美是误报主源：边界相似度→弃权带
7. 节点对齐歧义（重复结构）：TopK边际化+歧义高时弃权边类
8. 75条分类型后每格<10，per-type声明配宽区间
9. 聚合召回是系统召回天花板：显式声明条件化

## 七、论文故事线（一段话）

> 需求一致性检测在RE领域30年停留在句对级；"同一实体散布在正文+图+表"的**文档级多模态一致性任务本身是空白**（2024-2026文献确认）。我们观察到军事/工程SRS文档普遍内嵌born-digital源（Visio XML），它不仅是免费的感知层金标准，更使**感知误差分布可测**——这是纯VLM方法永远拿不到的东西。我们形式化一致性校验为译码问题D=η⊕ε，证明分离条件π>p与指数误差衰减，设计锚点校准+归属解码+共形弃权协议，在16份真实军事SRS上以provenance drift真实bug+75条人工裁决不一致+反循环变异协议评测，ECE和风险-覆盖前沿显著优于裸VLM与未校准融合。
