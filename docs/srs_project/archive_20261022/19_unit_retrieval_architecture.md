## 一、架构总览(4模块, 每个一句话职责)

```
┌─────────────────────────────────────────────────────────┐
│ 模块1·单元提取 (Unit Extraction)                          │
│ 职责: 每个模态一个提取器, chunk → [标题单元, *内容单元]     │
│   图: image_unit_extractor (锚点节点+VLM标题)  [va_colpali]│
│   表: table_unit_extractor (HTML行+表标题)    [unit_retr.]│
│   文: (待做: 章节块)                                       │
├─────────────────────────────────────────────────────────┤
│ 模块2·单元索引与打分 (UnitIndex, 统一)                     │
│ 职责: 单元向量集合的索引+查询打分, 唯一公式                  │
│   score = max(标题相似, top-k均值)  若gate                  │
│          top-k均值                  若无gate               │
│   图实例: gate=False  表实例: gate=True —— 参数差异非代码差异 │
├─────────────────────────────────────────────────────────┤
│ 模块3·通道组合 (route_combine, 与模态无关)                 │
│ 职责: 单向量通道与单元通道的查询级路由                       │
│   route = max(zscore(单向量), zscore(单元))  无参数        │
├─────────────────────────────────────────────────────────┤
│ 模块4·评测协议 (eval工具, 与算法分离)                      │
│ 职责: 4-fold×16文档 / 指令前缀 / R@1·R@5·MRR / 快照锁定     │
└─────────────────────────────────────────────────────────┘
```

**一句话**: 模块1决定"什么算一个单元"(每模态一个, 唯一的模态特定代码),
模块2~3对所有模态通用(一套代码), 模块4保证数字可信.

| 核心概念 | 定义 | 吸收的旧名词 |

## 五、v1.1改进: IDF特异性加权 + k=1统一最优 + 阻尼路由

多角度扫描实验(k∈{1,2,3,5,8} × IDF × 单元集 × RRF/阻尼路由)的结论:

**打分统一为IDF加权MaxSim(k=1)**:
- 深行查询只引用一行——k=3均值稀释唯一强匹配, k=1保精确
- IDF(=log(1+N/df))压制"序号=1"/"用户"类万金油单元, 放大特定单元
- k=1时gate退化为no-op: **两模态打分公式完全收敛**(图=表=IDF加权MaxSim)

**图实例补VLM元素单元**: 单元=锚点节点+VLM key_elements并集(互为冗余证据,
锚点零OCR误差, VLM覆盖无锚点图)——覆盖362→378/381图, R@5 +2.0

**路由加阻尼**: `max(0.8·z(dense), z(unit))`——单元通道跨场景均匀
(caption 0.738/深行0.748), dense场景依赖(caption 0.843/深行0.108),
故以单元为锚、dense阻尼辅助.

**弃用的角度(扫描证据)**: RRF两场景均劣(深行0.198!); 词法bigram覆盖无增益;
图侧任何与dense的融合均稀释.

## 六、单元子注意力(UAA): 学习聚合的收敛验证

> `algorithms/unit_attention.py` + `tools/eval_unit_attention.py`
> 用户诉求"算法味道/子注意力训练"的落地——**冻结表示+学习聚合**.

### 设计(回应表示学习失败的教训)

```
冻结表示源(3个)               学习(1个, ~500参数)
  ① BGE → sim_bge              α_i = softmax(MLP([sim_bge, sim_cmsc,
  ② CMSC投影头 → sim_cmsc                     idf, 13维结构特征,
     (跨模态对齐, 3724对预训练,                  5维查询上下文]) + κ·(sim·idf))
      此前替换BGE失败——现在作                        ↑warm-start残差
      为特征进入, 只能加信号)     score = Σ α_i·(sim·idf)
  ③ 结构特征: 节点类型/坐标/出入度/行位置/单元格数
```

- **warm-start**: logit含κ·value残差(κ=8), 初始状态精确=FIXED聚合器
  (softmax平滑MaxSim)——起点不回退, 训练只学结构修正
- **查询级上下文**(广播到每单元): 相似度分布的max/mean/std/熵/候选数
  ——让注意力区分"尖锐查询(深行型)"与"宽泛查询(caption型)"
- **信任初始化正则**: L2压制MLP偏离κ残差
- 4-fold文档级分离训练, CE损失, 段softmax向量化(秒级/折)

### 收敛验证结果(数字锁定: unit_attention_eval.json)

| 场景 | FIXED | UAA(学习, reg=50) | Δ |
|---|:---:|:---:|:---:|
| 图(evalset_v3) | 0.581/0.848/0.695 | 0.575/0.843/0.687 | ≈持平 |
| 表caption级 | 0.738/0.900/0.806 | 0.729/0.895/0.800 | ≈持平 |
| 表深行 | 0.748/0.892/0.801 | 0.748/**0.910**/0.804 | R@5+1.8 |

**结论(论文claim升级)**: 固定聚合器(k=1+IDF MaxSim)是学习注意力族的
**收敛不动点**——warm-start训练收敛回它(ΔR@1<1pt), 任何偏离都以
caption↔deep的此消彼长为代价(消融矩阵: 无正则→caption+2.3/deep-8.1;
混合深行训练→双场景略降). 零训练方法的合理性从"启发式"升级为
"学习验证过的不动点".

## 六、CMSC跨模态投影头的特征层集成(用户驱动设计)

> 回应"把多模态投影头结合进特征提取, 深度关联图/Visio/表/文字".
> CMSC双塔(proj_a=prose塔, proj_b=表/图塔, 3724跨模态对预训练)
> 三种集成方式全部实验过: 路由通道/聚合键融合/子注意力特征.

### 设计B胜出: 聚合键融合(固定公式, 零学习)

```
fused_sims = sim_bge + λ·cos(proj_a(查询), proj_b(单元))    λ=0.3
score = max_u[fused_sims·idf]      (融合先于IDF加权)
语义: CMSC决定"哪个单元是对齐命中"(跨模态实体级), BGE决定语义强度
```

| 集成方式 | 图R@1 | 结论 |
|---|:---:|---|
| 无(基线) | 0.582 | — |
| A: 第三路由通道 max-z | 0.607 | 与dense路由不可区分, CMSC通道z-score从未胜出 |
| **B: 聚合键融合λ=0.3** | **0.620** | **+3.8, 跨模态场景(自然语言→图节点)生效** |
| UAA子注意力特征 | ≈基线 | 学习收敛回固定公式, CMSC特征未被利用 |
| 表深行上B | 0.694(↓) | 同模态匹配BGE更强, 负结果——表实例fusion=0 |

**两级诚实结论**:
- 召回级(无重排): CMSC融合+3.8 R@1(0.581→0.619)——对无重排部署
  和小K重排有实际价值
- 重排级(K=10): 增益被cross-encoder吸收(O2a 0.663 vs 0.664)——
  精排器的强重排序吞掉了召回层的top-1精度差

### 实现位置
`UnitIndex(cmsc_fuse=0.3)`(algorithms/unit_retrieval.py): 构建期
proj_b投影单元入v3缓存, 查询期proj_a投影+fuse. 图门面默认开启,
表门面关闭(负结果). 模块文档已更新.

## 七、两阶段检索: 单元召回×cross-encoder重排(对比矩阵)

> `tools/eval_two_stage.py`, 重排器=BGE-Reranker-v2-m3(本地GPU, 确定性).
> 模块4(通道路由)之上新增模块5·精排层: 完整方法=单元召回→重排.

### 方法矩阵(对比方法vs核心方法)

| 编号 | 方法 | 角色 |
|---|---|---|
| B1 | dense单向量 | 基线(无重排) |
| B2 | dense top-10→全文重排 | **标准两阶段基线** |
| O1 | 单元检索 | 核心方法stage-1 |
| O2a | 单元top-10→全文重排 | 核心+重排(隔离通道因素) |
| O2b | 单元top-10→**单元片段**重排 | 核心完整版(深内容) |

**单元片段重排(S)的机制**: cross-encoder窗口512 token同样截断——
深行内容(char 800+)对全文重排也不可见, B2在深行上R@5仅0.365.
S把stage-1命中的top-3单元(sim·idf)前置为证据片段:
**stage-1选证据, stage-2验证**.

### 数字(R@1/R@5/R@10/MRR@10, 4-fold, top-10重排)

| 场景 | B1 | B2 | O1 | O2a | O2b |
|---|:---:|:---:|:---:|:---:|:---:|
| 图(1007q) | 0.515/0.776/0.846/0.626 | 0.622/0.828/0.846/0.710 | 0.581/0.848/0.902/0.695 | **0.664/0.889/0.902/0.760** | 0.567/0.871/0.902/0.691 |
| 表caption(1532q) | 0.843/0.942/0.961/0.887 | **0.867**/0.953/0.961/0.904 | 0.804/0.940/0.968/0.863 | 0.863/0.953/0.968/0.904 | 0.774/0.943/0.968/0.846 |
| 表深行(111q) | 0.084/0.330/0.365/0.179 | 0.251/0.365/0.365/0.299 | **0.784**/0.952/0.977/0.837 | 0.744/0.957/0.977/0.827 | 0.771/**0.970**/0.977/**0.854** |

### 三个结论

1. **单元召回抬升重排天花板并放大收益**(图): 同一重排器,
   O2a(0.664/0.889/0.760) > B2(0.622/0.828/0.710)——
   单元召回把R@10上限从0.846抬到0.902(+5.6), 重排收益随之放大.
2. **深行上全文重排被窗口截断反噬**: O2a R@1 0.784→0.744(降);
   片段重排修复: O2b R@5 0.970(+1.8), MRR 0.854(+1.7).
3. **短内容全文更优**(图/caption), **深内容片段更优**(深行)——
   passage选择应由内容深度决定, 是后续查询自适应的设计点.

## 八、对"上下文关联"主线的意义

特征提取(模块1+2)与关联组合(模块3)解耦后, 上下文关联系统(方向A)的
接入点变得清晰:
- 新增模态(如文本章节块) = 写一个单元提取器 + 一组参数, 模块2/3零改动
- 三模态统一后, 跨模态聚合(条目=图节点+表行+正文段)在同一表示框架内进行
- ROUTE扩展为多通道路由(max over N个z-score)是自然推广
