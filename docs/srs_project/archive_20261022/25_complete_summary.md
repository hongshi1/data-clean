## 我们的方法（O1-unit）

**核心思路**：不把文档压成一条文本→一个向量，而是按文档的天然结构单元（图的节点、表的行）分别向量化，查询对每个单元独立打分后取最大值。

```
score(查询, 表) = max over 所有行 [ cos(查询向量, 行向量) × IDF(行) ]
```

**三个组成部分**：
- `cos(查询, 行)` —— BGE模型编码查询和每一行，算余弦相似度
- `IDF(行)` —— 出现在很多表里的行（如"序号=1"）被降权，独特的行被升权
- `max` —— 取最高分的那行作为这张表的分数

**O1变体**（仅在GJB场景，因为画像概念只适用于该域）：
- **O1-TP-cc**：行前拼表标题（"表4功能划分。序号=1 功能=..."），给行携带上下文
- **O1-TP-cf**：cc基础上加池模糊IDF（用余弦相似度近似判断"哪些行很相似"，相似的行降权）
