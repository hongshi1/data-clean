
### 1.2 关键数据发现: 模板近重复文档

doc13/14/15/16(传输服务家族)是**模板复制的近重复文档**——相同行出现在
多表(6-10表)。诚实处理: **多gold**(任一含该行的表都算命中)。
- gold集分布: {1:117, 2:24, 3:9, 4:5, 5:8, 6:2, 7:3, 8:6, 9:1, 10:1}
- >10表(歧义退化, 如通用异常流行)28条拒绝
- 74条重复查询拒绝(LLM对相同行生成相同查询)

### 1.3 协议注意(诚实披露)

| 属性 | v3(262q) | v4(176q) |
|---|---|---|
| 文档覆盖 | 4/16 | 15/16(联合16/16) |
| gold | 单gold | 多gold(1-10表) |
| overlap均值 | ~0.1(反复制设计) | 0.224 |
| 词面方法难度 | 高(BM25-doc=0.069) | 中(BM25-doc=0.352) |

→ v4的绝对R@1偏高部分来自多gold与较高词面重叠; 跨场景比较需谨慎,
重排增益(+pt与显著性)是场景内自比, 有效。
