## 一、方案质变：Born-Digital 金标准

### 1.1 发现

16份.doc的**用例图/流程图/接口图全部是Visio嵌入对象**（OLE ObjectPool），内部是标准Visio XML（`visio/pages/page1.xml`），含**结构化Shape数据**：

```xml
<Shape>  <!-- 每个节点 -->
  <Text>创建服务工程</Text>              ← 100%准确的文字
  <Cell N='PinX' V='5.0'/>               ← 坐标
  <Cell N='PinY' V='8.0'/>               ← 坐标
  <Cell N='Width' V='2.0'/>              ← 尺寸
  <Cell N='Height' V='1.0'/>
</Shape>
```

### 1.2 数据规模

| 指标 | 数量 |
|------|------|
| Visio图 | 374个 |
| 结构化Shape | **11308个**（文字+坐标+尺寸） |
| 提取文字 | 2778个 |
| 准确性 | **100%（源文件直读，零视觉误差）** |

### 1.3 对方案的意义

```
之前: 多模态依赖VLM API(有幻觉/成本/不可复现)
现在: Visio XML直读 = 金标准(免费/准确/可复现/带坐标)
     VLM从"唯一来源"降级为"待验证的提取器"
```

## 五、评测设计

### 5.1 多模态通道评测（新）

```
对374个Visio图:
  Born-Digital提取 → 金标准节点集 G_i
  VLM提取 → 预测集 P_i  
  OCR提取 → 预测集 O_i

指标:
  VLM准确率 = |P_i ∩ G_i| / |P_i|   (幻觉率 = 1 - 准确率)
  VLM召回率 = |P_i ∩ G_i| / |G_i|   (遗漏率 = 1 - 召回率)
  OCR同理
  → 报告: 哪个通道更准/更全/更稳
```

### 5.2 一致性检测评测（沿用）

```
sc1 Gold Standard(242条) + 分层 + 真实单独 + hold-out
对比: B0多数类 / B1字符级 / B2 LLM / B3 ID-Graph / B4 ID-Graph+证据门控
消融: 无born-digital / 无图推理 / 无证据门控
统计: bootstrap CI + McNemar
```

## 九、图方法综合评测（7种方法）

### 9.1 方法对比表

| 方法 | P | R | F1 | 特点 |
|------|---|---|-----|------|
| 语义图连通分量(固定阈值0.6) | 1.000 | 0.750 | 0.857 | 精确, 规则 |
| Louvain社区发现 | 1.000 | 0.688 | 0.815 | 精确, 自动聚类 |
| 谱聚类(拉普拉斯) | 0.625 | 0.625 | 0.625 | 粒度不匹配 |
| 学习检测器(逻辑回归) | 0.571 | 1.000 | 0.727 | 高召回, 多误报 |
| **图注意力(学习边权重)** | **1.000** | **0.812** | **0.897** | **最优, 学习阈值** |
| **双空间(拓扑+文本)** | **1.000** | **0.812** | **0.897** | **最优, 可解释** |

### 9.2 科学发现

```
1. 学习边权重 > 固定阈值 (0.897 vs 0.857)
2. P/R权衡: 图方法高精确(1.0), 学习方法高召回(1.0), 混合平衡
3. 方法演进: 固定阈值→学习权重→双空间
4. 双空间可解释: 矛盾 = 同实体(topo>0.7) + 文本不相似(text<0.6)
```

### 9.3 双空间方法（核心贡献）

```
空间1(拓扑): 异构图嵌入(metapath2vec) → 编码实体归属
空间2(文本): 文本相似度(编辑距离归一化) → 编码名称差异
矛盾检测: 同实体(topo高) + 文本不相似(text低) → 矛盾

例: '资源占用监控' vs '界面配置保存'
  topo=1.0 (同一实体), text=0.0 (完全不同) → 矛盾
```
