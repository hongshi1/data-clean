> 姊妹文档: `pair_expansion_plan.md`(BGE匹配512对,已完成) | `pair_dataset_spec.md`(canonical规范) | `mutation_master_plan.md`(48类体系)

## 0. 摘要与核心原则

**目标**: 将pair原料从738对(366锚点+372 L1表侧复用)扩至 **~5,500-6,500条训练条目**，同时保证冻结评测集(clean130/md166)上bAcc单调不降(±ε)。

**五条设计公理**(全部由既有负结果反推):

| 公理 | 内容 | 依据 |
|---|---|---|
| A1 表面同构 | 一切进入训练的pair必须经T1/T2/T3模板族编译, 表面形态与域内零漂移 | v6-v10"模式绑定"三连验证; 外部原生句子直混=表面分布漂移 |
| A2 内容为唯一自由变量 | 扩容只扩充content槽的语义流形, 不动(主体/侧/模板)结构 | canonical v2.1核心设计 |
| A3 标签约定域内化 | 外部样本的标签必须在域约定κ_D下重新校准, 只取约定一致的高置信子集 | "GJB的不一致是领域约定"(K3), 零样本全报警的根因 |
| A4 剂量+棘轮 | 外部/合成数据按族配额入场, 每批必须通过冻结评测棘轮门 | 0.940>0.749的直接教训 |
| A5 对称构造 | 每个变异对(不一致)与原对/等效对(一致)同源成对保留, 算子级1:1 | 防止"数字出现⇒不一致"类捷径 |

**一句话方案**: 外部数据**转译不混入**(重铸进T模板+标签域校准+探针优先), 合成数据**三轨道分真值等级**(确定性枚举L1 > LLM受控生成L2 > 银标L3只进训练), 全程**闭环棘轮**(QC→对抗验证→分布距离→训练→冻结评测→发布)。

## 1. 问题形式化

### 1.1 Pair的分解: 表面 × 内容

canonical v2.1的模板族给出了天然的因子分解。每个pair:

$$x = (p, h) = \tau_\sigma(z), \quad z = (s, a, b, c_A, c_B), \quad \sigma \in \mathcal{T} = \{T_1, T_2, T_3\}$$

- $\tau_\sigma$: 表面模板(T1对照式/T2规定式/T3文档式), 槽位 = 主体$s$(该功能/该接口/系统)、侧$a,b$(正文/能力表/流程图/接口表…)、内容$c_A, c_B$
- $z$: 内容语义(唯一自由变量)

域内分布 $P_D$ 集中在: $z$~GJB实体空间(编号/参数/功能名), $\sigma \in \mathcal{T}$。
外部NLI分布 $P_E$: $z$~通用语义(维基/新闻/合同), $\sigma$~自然句式(英语或中文口语)。

### 1.2 为什么直接混入必败: 域适配界

Ben-David域适配界: 对任意假设$h$,

$$\epsilon_E(h) \le \epsilon_D(h) + \tfrac{1}{2}\, d_{\mathcal{H}\Delta\mathcal{H}}(D, E) + \lambda^*$$

- $d_{\mathcal{H}\Delta\mathcal{H}}$: 假设空间分歧散度(表面分布差距)
- $\lambda^* = \min_h [\epsilon_D(h) + \epsilon_E(h)]$: **标签约定分歧**(最优假设下两边联合误差)

对外部NLI直混: $d$大(句式+语言+长度全漂移), $\lambda^*$大("图省略参与者=良性"这类κ_D约定在NLI中不存在, NLI的"矛盾"是纯语义否定)。混合训练的最优解是牺牲域内边界去拟合外部——精确对应实测的0.940→0.749/0.909/0.653。

**本方案对两项同时动刀**: 转化算子$\Phi$把$\sigma$强制重铸进$\mathcal{T}$(压掉$d$), 标签域校准+选择性引入压掉$\lambda^*$。

### 1.3 标签约定与标签保持率

定义域内标注函数$\kappa_D$(K3约定, 已由934条双LLM金标+48类体系实例化)与外部标签函数$\kappa_{ext}$。引入**转化校准样本**: 抽$n=200$条外部对, 经$\Phi$转译后交双LLM在域约定下复判:

$$\hat\delta = \frac{1}{n}\sum_{i=1}^{n} \mathbb{1}\big[\kappa_D(\Phi(x_i)) \neq \kappa_{ext}(x_i)\big], \quad \text{要求 } \hat\delta \le 0.10$$

$\hat\delta$超标的数据源**整体降级或弃用**(只留探针用途), 这是对A3的可执行化。

### 1.4 用途分层: 外部数据的三种角色

| 角色 | 机制 | 污染风险 | 对应公理 |
|---|---|---|---|
| **U1 探针(eval-only)** | 冻结的捷径诊断集, 永不进梯度 | **零**(结构性保证) | 独立于训练 |
| **U2 定向补族(训练)** | 转译+域校准+族配额+棘轮, 只补弱族(D/E) | 受控(剂量+门控) | A1/A3/A4 |
| **U3 编码器正则(预训练)** | 外部对只用于encoder的对比预训练 pretext, 分类头只在域内数据上训练 | 间接(特征级) | 实验 gated |

U1是纯收益: PAWS一致难例探针直接量化"模型是否在词面重叠上误报"(v5全报警病灶), FEVEROUS表格探针量化数值/结构蕴含能力——这两项是**无论是否采用U2都应立即建**的资产。

## 2. 问题1: 外部数据转化协议

### 2.1 总协议: 五阶段转化漏斗

所有外部源走同一条漏斗(与canonical六阶段管线对接, 从Stage3表面化起接入):

```
Stage-E1 解析: 原始格式 → (文本A, 文本B, 三类标签, 证据)
Stage-E2 筛选: 结构性硬过滤(见各源协议) + 标签二值化(drop neutral/NEI)
Stage-E3 转译: 机器翻译→领域词典后编辑; 实体白名单过滤(人名/地名/外文专名→改写或弃)
Stage-E4 重铸: 槽位抽取(s,a,b,c_A,c_B) → T1/T2/T3编译(与域内同构)
Stage-E5 质控: ①标签保持率校准(n=200双LLM) ②7项合格判据(§4.1) ③剂量配额 ④棘轮门控
```

产出schema直接复用canonical, `source="nli_external_translated"`, provenance带`origin="converted:<raw_id>"`与`protocol="label-calib"`, 全程可审计。

**转译后防污染的四层保障**(回答"如何保证不污染域内判别"):
1. **表面同构**: $\sigma \in \mathcal{T}$由构造保证(Stage-E4);
2. **剂量配额**: 全局$\rho_{ext} \le 15\%$训练集, 单族$\le 5\%$(D/E族例外, 见§3.6);
3. **棘轮+冻结评测**: 每批经§3.6闭环, clean130/md166只在最终报告两次, **门控用独立gate集**(doc03 dev + train文档held-out 20%), 防门控集过拟合;
4. **行为污染矩阵**: 延续既有协议(mdeberta/erlangshen行为验证), 转译对与原版对照, 监测标签翻转率。

### 2.2 逐数据源转化协议

#### a) FEVEROUS → "表格证据↔文本声明"对(A/C族同构) — **可行, 定位U2小剂量+U1探针**

FEVEROUS的本质与sc1/anchor管线同构: 声明(claim) vs 结构化证据(表格行+句子)的核对, 正是"表格内容↔文本声明"pair。已有池15,000条(claim/label/evidence, evidence含表格行结构)。

转化函数(带前置条件):

$$\phi_F(c, E, \ell) \text{ defined} \iff E_{tab} \neq \emptyset \;\wedge\; |\mathrm{rows}(E_{tab})| \ge 2 \;\wedge\; \ell \in \{\text{S}, \text{R}\} \;\wedge\; \mathrm{translatable}(c)$$

- premise = `τ(文档3.2.1规定: <表格行内容串>)`, hypothesis = `τ(文档4.1.2记载: <claim译文>)`
- label: REFUTES→inconsistent, SUPPORTS→consistent; **NEI弃用**(二分类无对应; 部分NEI中"存在性/成员性声称"可转为可证据反驳项, 归入S2机制, 不直接进训练)
- 值得取的内容: 数值比较/隶属关系/计数类的claim(与A族/C族模式同构); 纯实体事实(人名球队)被实体过滤拦截
- 预期: 池内筛后~2-4k候选 → 转译+QC后**~800-1,500条**; 探针集另取200条(表格蕴含S/R各半)

#### b) ContractNLI → "条款A↔条款B"对(E族同构) — **可行, 两种切法**

已有池5,642条(English, premise=合同上下文条款, hypothesis=声明, 三类标签)。

**切法1(直接NLI项)**: contradiction项 → `τ(文档A条款规定: <clause译文>)` vs `τ(文档B条款规定: <hypothesis译文>)` → inconsistent; entailment→consistent; neutral弃。

**切法2(跨文档同条款配对, 更接近SRS形态)**: ContractNLI的41类条款(保密范围/例外披露/期限/违约…)与GJB的容错/安全/保密/权限条款同构。对每条款类型$t$, 从不同合同文档抽取真实条款$\{c_i\}$, 组$(c_i, c_j)$:
- 义务同构(同为"不得披露"的不同表述) → consistent(条款级释义难例)
- 义务冲突(禁止 vs 允许; 需经 vs 无需) → inconsistent(E族: 权限/义务矛盾)
- 标签由ContractNLI官方hypothesis对两条款的判定推导, 分歧者弃
- 预期: 切法2产出**~500-1,000条**; 语义上"同主题跨位置"正是SRS的pair形态

#### c) OCNLI / CMNLI — **OCNLI选择性可行; CMNLI仅U3**

OCNLI(人工标注, 质量高): 只取**矛盾类的高词重叠事实型子集**:

$$F_{sel}: \ell = \text{contradiction} \;\wedge\; \mathrm{ov}(c_A, c_B) \in [0.5, 0.85] \;\wedge\; |c| \in [15, 60] \;\wedge\; \exists(\text{数词} \lor \text{量化词} \lor \text{共享实体})$$

高重叠+矛盾 = "词面相似但语义分歧", 正是TERM-01/02(同义异名/同名异义)的领域外同构——这是D族(当前≈随机)最缺的监督信号。两侧须共享主体实体(跨句同指), 否则弃(无法填主体槽)。筛选后再经转译重铸进T2(规定式)。预期OCNLI 33k池筛出~1k, **训练用量300-500条**。

CMNLI(机翻MNLI, 标签噪声+翻译腔): **不进任务训练**(U2禁用), 仅U3——作encoder对比预训练pretext(§2.3)与污染矩阵对照。

#### d) PAWS-X zh — **一致难例价值最高, U1探针为主+U2小剂量**

- **释义对** → consistent难例: 高词重叠但一致, 直接对抗"词面重叠⇒误报"捷径(v5全报警病灶的解药)。49.4k池中释义类~44%, 筛中文流畅+长度约束后取500-1,000。
- **非释义对** → inconsistent难例: 词序/角色互换型("A向B提供"vs"B向A提供")与LOGIC-04(数据流方向)/B族(顺序)同构, 取词交换型子集~300。
- **探针集(最优先)**: 200条冻结(释义100+非释义100, 重铸进T模板), 每次训完报告"词重叠捷径分" = 误报率(释义对判不一致比例)。**这个探针不训练任何模型就应立即建**。

## 3. 问题2: 可控合成协议

### 3.1 三轨道 × 真值等级

| 轨道 | 机制 | 真值等级 | 规模目标 | 依赖 |
|---|---|---|---|---|
| **S1 模板-槽位枚举** | 参数族×值域×操作符系统枚举, Z3等价归一 | **L1构造真值**(标签确定性) | +1,500-2,500 | srs_kb.json+语料挖掘, 零LLM |
| **S2 LLM上下文受控生成** | 真实SRS上下文中生成+三重验证 | **L2验证银标** | +1,000-1,500 | LLM(cache)+证据核验 |
| **S3 锚点视图复用** | anchor多模态证据的成对视图组合(372 L1的推广) | L1/L2 | +500-800 | 双LLM裁决(cache) |

现有18算子(chunks级, 594条srs_pair_mutation)保留为S0基线; S1/S2/S3是其受控升级——区别在于: **合成对象的语义从"随机扰动"变为"语料锚定+类型定向+标签可构造证明"**。

### 3.2 S1: 模板-槽位合成(回答"数值参数系统化枚举")

**第一步: 约束库存量挖掘**(确定性, 从16份SRS+srs_kb.json):

$$\mathcal{I} = \{(s, f, u, v, \circ)\}, \quad f \in \mathcal{F}(\text{23参数族+13接口+10单位族}),\ u \in \mathcal{U}_f,\ v \sim \hat p_f(v),\ \circ \in \{\le, \ge, =, \in\}$$

- $\hat p_f(v)$: 值域分布**从语料挖掘**(每参数族的真实取值区间/典型值/单位习惯), 不用人工假设——这是"合成pair语义上与真实SRS一致"的第一道保证
- 主体池$s$: 语料真实实体(功能名/接口名/设备名), 保留GJB编号风格

**第二步: 关系判定与标签**(标签=构造性真值, 非LLM):

$$r(e_A, e_B) \in \{\mathrm{equiv}, \mathrm{conflict}, \mathrm{subsum}, \mathrm{orth}\}, \quad y = \kappa_D(e_A, e_B) = \mathbb{1}\big[\mathrm{same}(s,f) \wedge \neg\mathrm{equiv}(v_A, v_B)\big]$$

关键点——**域约定显式化**(κ_D而非纯逻辑):
- $\mathrm{equiv}$由Z3单位归一判定: 0.2s↔200ms ⇒ equivalent ⇒ consistent(对应P2数值等效族)
- 同参数不同值 ⇒ **inconsistent(文档级)**, 即使逻辑上$\le 100$蕴含$\le 300$(PARAM-01的域约定: 同参数两处不同值=文档矛盾)——κ_D从934条裁决金标反向编译, 变异≠不一致, 约定说了算
- $r = \mathrm{orth}$(不同参数或不同主体) ⇒ 弃或改铸
- subsum关系单独打标, 进"难例正样本"讨论组(域约定上是不一致, 但需抽检确认金标一致)

**第三步: 对称构造(公理A5)**: 每个conflict对, 同枚举格点生成equiv对(换单位不换值), 数值密度/长度严格匹配——模型无法用"有数字"作捷径, 只能学关系。

**第四步**: T1/T2/T3编译(每对3表面, surface字段受控), 全量带context锚(引用源chunk)。

产出定向: A族(PARAM-01/02/05/06/07)与D族(TERM-06量纲)为主, 即Z3与词典通道的"训练燃料"。

### 3.3 S2: LLM上下文受控生成(回答"LLM在真实上下文中生成新pair, 带证据验证")

**生成协议**(全部走algorithms/llm_client.py cache=True, runs协议记录config+git_sha):

1. **种子选择按覆盖缺口**: 覆盖矩阵(48类×16文档×8场景)做χ²缺口检测, 定向生成稀缺格子(如sc5子功能12条→目标200, B族序列对, E族合规对); **生成源chunks仅限train文档(01/02/05/06/08-16), 04/07/03一律禁入**——结构防泄漏
2. **生成prompt骨架**: 给真实chunk+上下文(表格行/图节点/正文), 要求产出候选声明对: (i)释义对(应consistent) (ii)受控扰动对(指定类型$T_k$的值/术语/顺序/存在性扰动, 应inconsistent) (iii)每对附"变异说明+证据引用"
3. **三重验证环**(每条必过):
   - **V1 双LLM裁决**: GLM+Kimi独立判(域约定prompt, 复用pair_expansion_plan协议), 一致→采纳
   - **V2 证据核验(确定性)**: 存在性/成员性声称与context.diagram实际节点/表格行比对——直接复用"19.4%声称被反驳"机制, 被反驳→隔离(evidence_quarantine)
   - **V3 Z3数值归一**: 含数值的对做单位归一等价判定, 与LLM标签冲突→以Z3为准
   - 分歧→CoT仲裁→仍分歧→unsure→quarantine(**永不进测试**)
4. **配额**: 每(文档×场景×类型)上限, 生成温度适中, 拒绝"顺滑假文"(见§4.1域过滤)

产出: L2级(验证银标), 只进训练+快照计数, 不进clean130/md166/gold。

### 3.4 S3: 锚点视图复用(372对L1表侧的系统化推广)

anchor的原始证据集 = $\{e_1, ..., e_k\}$(正文/表格/图/接口表多模态), 当前只用了1-2个视图方向。形式化:

$$\mathrm{Views}(a) = \{(e_i, e_j) : i \neq j\}, \quad |\mathrm{Views}| = k(k-1) \text{(典型 } k{=}3 \Rightarrow 6\text{)}$$

- 现有: 表→图(366) + 表→图复用(372); 待开发: **表↔文、图↔文、跨场景同名实体对**
- 每个新视图走双LLM裁决标注(cache, prompt适配侧对), 标签与已有视图的一致性作交叉校验——同anchor不同视图标签翻转 ⇒ 抽取噪声信号, 进复核队列
- 纯复用既有多模态context, **证据成本为零, 只付标注API(cache)**

### 3.5 比例控制与闭环(回答"合成:真实比例如何控制")

**训练目标(族级加权混合)**:

$$\mathcal{L}(\theta) = \mathbb{E}_{D_{\mathrm{in}}}[\ell(f_\theta(x), y)] + \sum_k \lambda_k \mathbb{E}_{A_k}[\ell(f_\theta(x), y)], \quad \lambda_k = \frac{\rho_k}{1-\rho_k}\cdot\frac{|D_{\mathrm{in}}|}{|A_k|}$$

**族级配额表**($\rho_k$ = 该族中增强条目占比上限):

| 族 | 现状 | 合成配额(S1+S2+S3) | 外部配额(U2) | 理由 |
|---|---|---|---|---|
| A数值 | Z3=0.858强 | ≤80%(L1为主, 构造真值) | ≤5% | 确定性标签可大量合成 |
| B顺序时序 | 待实现 | ≤70% | ≤5% | 序列比对可构造 |
| C结构存在 | 0.768 | ≤60% | ≤5%(FEVEROUS表) | 证据核验可把守 |
| D术语 | **≈随机(最弱)** | ≤50% | **≤20%(OCNLI+PAWS重点投放)** | 最缺监督, 外部同构性最好 |
| E合规 | ≈随机 | ≤50%(规则引擎衍生) | ≤20%(ContractNLI) | 同上 |
| F语义惯例 | v12=0.940(最强) | **≤30%** | **≤5%** | 最强族, 增强风险>收益 |

**全局约束**: 真实锚点系(含视图复用)条目 ≥ 训练集25%; $\rho_{ext}^{global} \le 15\%$; 合成:真实 ∈ [1:1, 3:1]。

**闭环流程(每批增强$A_b$)**:

```
1. 单条QC(§4.1七项) → 2. 去重(min-hash内容槽对) → 3. 对抗验证: 训练g: real vs synth, gate AUC≤0.65
→ 4. 分布距离: BGE内容槽embedding FD, gate FD(A,D_train) ≤ FD(D_train,D_dev-real)[自校准阈]
→ 5. 覆盖矩阵χ²检查(类型×场景×表面无空洞/无爆块) → 6. 训练候选模型M'(D∪A_b@ρ_k)
→ 7. 棘轮门控: bAcc(M'; E_gate) ≥ bAcc(M; E_gate) − ε, ε=0.005
   失败→ρ_k减半重试一次→再失败→弃批(记录runs)
→ 8. 接纳: canonical更新+build_data_manifest.py同步+快照测试+runs记录
```

**棘轮的形式保证**: 接纳序列满足 $bAcc_1 \le bAcc_2 + \epsilon \le \cdots$(非回退链), clean130/md166仅在链终点各评测一次(报告集与gate集分离, 防门控过拟合)。

### 3.6 分布偏移监控(回答"如何避免合成数据的分布偏移")

四项互补度量, 各堵一类偏移:

1. **表面偏移**: 结构性为零(全部经$\mathcal{T}$编译)——由构造保证, 抽检模板合规率100%。
2. **内容偏移**: Fréchet距离
   $$\mathrm{FD}(P, Q) = \|\mu_P - \mu_Q\|_2^2 + \mathrm{tr}\big(\Sigma_P + \Sigma_Q - 2(\Sigma_P\Sigma_Q)^{1/2}\big)$$
   在BGE(1024d, bge_local)内容槽embedding上计算; **阈自校准**: 合成vs真实的FD ≤ 真实train vs 真实dev的FD(合成分布差距不得超过真实内部差距)。
3. **可判别性偏移(对抗验证)**: $\text{AUC}(g^*_{\text{real-vs-synth}}) \le 0.65$; 超标→合成"太假", 回炉(增强$\hat p_f(v)$语料锚定/LLM生成温度)。
4. **标签先验偏移**: 每切片(type×surface)的P(inconsistent)与真实锚点先验(30-70%)偏差≤15pt; 对称构造在算子级强制1:1。

配套: 逐切片KS检验(长度/数字密度/实体密度), 人工抽检每批100条(与双LLM的Cohen's κ ≥ 0.6)。

### 5.3 风险与对策

| 风险 | 对策 |

### 5.4 不做清单(死路防护, 接续项目"死路清单"惯例)

4. 超族配额的剂量投放; 无棘门控的批量合入
5. 无cache的LLM调用; 无provenance的pair
6. 英语原文直接进训练(必须转译+域过滤)
7. 在测试文档(04/07/03)上做任何生成/挖掘
