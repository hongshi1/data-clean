## 一、核心叙事(方法定位)

**我们的方法 = κ_D条件化流水线分派一致性判别**
```
Pair → [阶段1: numeric(κ_D数值)] ──命中→ 提前报出(PARAM族)
     → [阶段2: quote(引号恒等)]  ──命中→ 提前报出(TERM/ENUM同表面)
     → [阶段3: term(术语消解)]   ──命中→ 提前报出(TERM-01)
     → [阶段4: enum(集合比对)]   ──命中→ 提前报出(ENUM/图元素)
     → [阶段5: verify(证据核验)] ──命中→ 提前报出(结构缺失)
     → [阶段6: nli(v19语义)]    ──兜底→ 语义残差
```
**提前检出价值**: 结构性/数值性不一致在前段通道即报,可解释+可溯源+零NLI成本。

## 六、关键技术决策

1. **金标不参与训练**(冻结),只在终点报出
2. **单标签桶报acc**,混合桶报bAcc(修正v3的退化bAcc误读)
3. **GLM抽样评测**(全量太慢),分层抽样保证每类型≥30条
4. **Z3 baseline**: 把pair的数值声明解析成约束,求可满足性(不可满足=不一致)
5. **检出深度**: 阶段序号1-6,体现"提前检出"的流水线价值
6. **类型统一映射**: 金标的ACTOR_MISSING等→C族;image的DIAGRAM_EXTRA→C族
