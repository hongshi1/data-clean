# Baseline双块对比: 原生数据集 vs 外部数据集(论文实验章节底稿)

> 版本: v1.0 | 2026-10-08 | 数据: runs/master_table_final_v3, public_nli_clean_eval, per_item_predictions, angle_oracle_routing

## 评测协议(合理性依据)

1. **同批样本**: 全部方法在完全相同的条目上评测(分层采样seed=42, 方法间共享, 不各自采样)
2. **指标**: P/R/F1(positive=inconsistent), **强制附带报警率**——F1在真比率高的集合会奖励"全报警"退化策略(实证: v6 md F1=0.847恰=全报警基线), 故报警率是防退化判据
3. **污染格标注⚠+行为验证**: 训练集内数据格不作能力主张; 污染判定不看文档声明, 用背诵级成绩实证(Erlangshen@OCNLI F1=1.000=实锤; mDeBERTa@XNLI比干净格+0.142)
4. **阈值诚实声明**: v9的th=0.2为测试集后验选点(方法论缺陷已记录, 应在验证集定标); 其余方法用默认0.5
5. **Oracle与固定路由分离**: oracle(测试集选优)只作上界, 部署用固定元数据映射表

## 块二: 外部数据集(中文NLI公开基准)

### 外部数据集构造构成(明示)

| 项 | 说明 |
|---|---|
| **选型理由** | 中⽂NLI三⼤标准基准(XNLI-zh/CMNLI/OCNLI)是唯一与本任务形式兼容(句对+矛盾标签)的公开数据集; 语⾔匹配(中⽂); RE域⽆公开中⽂SRS不⼀致对数据集(本数据集的学术价值) |
| **划分来源** | XNLI-zh=官⽅test(5010); CMNLI=官⽅dev(12441, 其"test"实为dev副本已剔除防重复); OCNLI=标准化test release(10097, 标签语义逐条验证: 加强vs弱化=矛盾✓) |
| **转换协议** | NLI三分类→⼆元: contradiction→inconsistent(报警); entailment/neutral→consistent(不报警)——依据: 不⼀致性检测是报警/不报警决策, "⽆法证明⽭盾即不报警", 与⽭盾检测⽂献⼆值化惯例⼀致; label_raw保留三分类供分析 |
| **采样** | 分层100/类×3类=300/源, seed42, ⽅法间共享同批 |
| **角色定位** | 外部效度/泛化/遗忘测量——**不作领域能⼒主张**(域迁移必然损失) |
| **污染矩阵(行为验证)** | XNLI→mDeBERTa⚠(+0.142实证); CMNLI→全干净(Erlangshen 0.910正常⽔平); OCNLI→Erlangshen系⚠(F1=1.000背诵实锤, 含QLoRA继承) |

### 块二三条结论

1. **零样本基座最强**(Erlangshen 0.922): 域外泛化是NLI预训练红利, 微调必付遗忘代价
2. **遗忘梯度与特化深度成正比**: v5(-0.045)→v6(-0.037)→v8(-0.153)→v9(崩溃)——CCT/多场景训练加深域内判别的同时加深遗忘; v9(Qwen⾮NLI基座+纯SRS训练)=完全特化(0.2-0.3), 与Erlangshen系形成**特化-泛化解耦的独⽴证据**
3. **正确解读**: 外部集衡量"微调代价"⽽⾮"能⼒上限"; 部署不需要外部泛化(纯SRS场景), 但学术上必须报告

## 我们的方法与baseline的本质差异

| 维度 | 零样本/LLM基线 | 我们(QLoRA系+路由) |
|---|---|---|
| **知识来源** | 预训练/提示词 | GJB域内适配(变异+真实锚点+难例负样本+CCT反事实) |
| **难例负样本** | ⽆ | 109条良性省略作consistent难负——唯⼀修复全报警退化的⼿段(P 0.308→0.52+) |
| **反事实训练** | ⽆ | 表⾯CF(同内容换模板→KL不变性)+内容CF(标签翻转敏感性) |
| **架构** | 单⼀模型单阈值 | **多角度路由**: 元数据(scene,dtype)→13角度×4⽅法矩阵→角度最优检测器 |
| **失败模式** | 全报警(报警率100%)或漏检(LLM R=0.6) | 判别性报警(37-60%)+可abstain(conformal) |
| **部署成本** | GLM-5需API/本地LLM慢(秒级) | 330M-1.5B本地毫秒级, RTX 4060 |

**一句话**: baseline⽤通⽤能⼒硬套任务, 我们把"域惯例知识+⻆度先验"注⼊轻量模型与路由架构——域内+0.09(0.982 vs 0.887最优基线), 真实场景从"全报警退化"变为判别性检测(0.798)。
