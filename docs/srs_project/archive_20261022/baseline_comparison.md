- 论文报告时对污染格加脚注, 干净对角线为有效比较

## 核心发现(论文叙事)

### 1. 域内优势: 330M微调模型 > 大模型 (论文主卖点)

SRS基准上 QLoRA **0.985** vs GLM-5 **0.887** (+0.098)。
关键差距在召回: QLoRA R=0.993 vs LLM R=0.812 —— **微调模型抓住99%的不一致, LLM漏掉19%**。
LLM零样本对SRS领域术语类不一致(TERM-01~08)识别弱, 需要领域适配。

### 2. 域外代价: 灾难性遗忘可量化

干净XNLI-zh上: QLoRA 0.803 vs 基座Erlangshen 0.909 (-0.106)。
遗忘量与训练量正相关(v2:-0.057 / v5:-0.072 / full:-0.104)。
→ 未来工作: 回放策略(混入原始NLI数据重训)。

### 3. 任务难度天花板: 人工金标上所有方法~0.41-0.44

包括GLM-5在内**全部方法**在真实金标上F1≈0.41-0.44 (P≈0.27, R=1.0)。
LLM把23条里22条判为不一致 —— 与QLoRA行为一致。
→ 结论: 真实语料中"合理省略 vs 真实矛盾"的区分是**任务本质难点**, 非我们方法独有缺陷。
→ 已定位根因(变异模板只有"缺失=矛盾", 无"缺失但合理"反例), 修复方案=220条良性差异负样本(数据已备: `benign_train_pool.json`), 重训待电脑资源允许时进行。

### 4. 污染警示(方法论贡献)

Erlangshen-OCNLI 100% vs XNLI 0.909 → **+9个点的虚高**。
与我们合成集教训同构: 训练分布内虚高, 分布外才是真实能力。
论文中应双层报告: 域内上限 + 域外泛化。

## v7多场景扩展(最终轮: 多文档金标 + SOTA基线 + 跨场景发现)

### 多文档金标(md_gold, 577→308唯一条, 16文档4场景)

构建协议: scene_tier1的579条结构差异(能力表↔用例图/接口表↔接口图/流程图↔能力表/子功能表↔功能图) →
CoT少样本裁决(GLM-5, 缓存可续) → 577有效(255真+322良性) → 文本级去重308条
发现: 47%文本重复率(同差异跨pair重复检出)

### v7(多场景良性训练) vs v6 vs mDeBERTa — 跨场景泛化

| 测试集 | v6 | v7 | mDeBERTa | 场景构成 |
|---|---|---|---|---|
| md_doc047(18) | 0.839(全报) | 0.60(P=0.86) | **0.867** | 72%真矛盾 |
| md_sc3(148) | **0.848**(全报) | 0.61(P=0.85) | 0.795 | 74%真矛盾(接口场景) |
| clean130 | 0.602 | 0.602 | 0.471(全报) | 31%真矛盾(doc02模式) |
| bench300 | 0.975 | **0.978** | 0.715 | 合成变异 |
| 金标v1(23) | 0.545 | - | 0.429 | 26%真矛盾 |

**核心发现(论文的诚实结论)**:
1. **场景先验差异**: 能力表场景56%良性(粒度惯例) vs 接口场景74%真矛盾(组件缺失=数据流断裂) — 报警策略需场景校准, 单一策略无法全域最优
2. **v7跨场景高精确率(0.85+)**: 多场景良性训练买到精确率, 但在真矛盾密集场景召回不足
3. **mDeBERTa零样本在多文档结构金标上强(0.795-0.867)但doc02模式全报警** — 零样本能力也不均匀
4. **域内优势稳固**: QLoRA(0.978) > GLM-5零样本(0.887) > GLM-5 few-shot CoT(0.845@193子集) > mDeBERTa(0.715)
5. few-shot CoT(含4例域内演示+推理链)仍不敌微调 — LLM提示的上限证据

### 方法形式化(三组件+消融)

1. **QLoRA领域适配**: Erlangshen-330M + LoRA(r=8, query/value/FFN注入) — 消融: v5 vs 基座
2. **难例负样本合成**: 良性结构差异(图省略惯例)作为consistent难负样本 — 消融: v5(无) vs v6(+0.213 P)
3. **多表面形式训练**: 跨场景模板(sc1/3/4/5+doc02结构) — 消融: v6(单场景) vs v7(跨场景P 0.85)
4. 阈值校准: th=0.9 (clean130 +0.034 F1)
