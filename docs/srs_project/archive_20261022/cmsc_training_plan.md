## 二、三目标联合预训练

### 目标1: CMSC(跨模态结构对应) — 已验证

```
信号: GJB四位置实体共现(prose↔table↔diagram↔trace)
数据: 3,724对(1,544实体, 6种模态组合)
损失: 对称InfoNCE(τ=0.07, batch 48)
结果: R@1 0.060→0.112(+87%), R@5 0.177→0.560(+216%)
```

### 目标2: GMC(图结构变异对比)

```
信号: 对锚点图做确定性结构变异 → 生成结构敏感负例
变异算子(对应四类不一致):
  节点删除 ↔ 功能缺失
  边反转   ↔ 方向矛盾
  类型混淆 ↔ 关系错误  
  标签变异 ↔ 术语错字

数据: 373图 → 每图生成4种变异 → ~1,500正负对
损失: 对比损失(正确图 vs 变异图, 共享编码器)
预期: 教编码器区分结构相似的图 → 图检索精度提升
```

### 目标3: MER(表格实体恢复)

```
信号: 掩码表格单元格 → 从行列上下文恢复
数据: 1,207张表(自监督, 无标注)
损失: 掩码恢复交叉熵(仅表格模态)
预期: 学到GJB表格共现规律 → 低置信恢复=模式异常→检测信号
```

### 联合训练

```
L_total = λ₁·L_CMSC + λ₂·L_GMC + λ₃·L_MER
  λ₁=1.0, λ₂=0.5, λ₃=0.3(初始, 可调)

架构:
  backbone: BGE-large-zh(326M, 冻结, 特征预计算)
  heads:
    proj_cross: 1024→256(CMSC用)
    proj_graph: 1024→256(GMC用)  
    head_mer: 256→词表(MER用, 仅表格模态)
  
训练协议:
  Stage 1: CMSC单独训练(80 epoch, ~30s)
  Stage 2: +GMC联合(30 epoch, 图变异数据)
  Stage 3: +MER联合(30 epoch, 表格掩码数据)
```

## 三、下游集成

```
预训练完成后:
  proj_cross → 替换三模块MFE中的BGE原始向量
  proj_graph → 图检索通道(VA-ColPali的查询编码器)
  head_mer  → 表格异常检测通道(进黑板)
```
