## 三、方法(最终: SRS-Calib = CCT四组件, 全消融验证)

```
SRS-Calib = QLoRA领域适配 + 难例负样本合成 + 反事实一致性训练(CCT) + 阈值场景校准
```

1. **QLoRA领域适配**: Erlangshen-330M + LoRA(r=8, query/value/FFN注入, 1.77M可训练参数)
   消融: 基座零样本bench 0.644 → 微调 0.980 (+0.336)

   消融: v7→v8 跨场景P 0.844→0.862且R 0.443→0.615(+0.17), clean130 0.587→0.629, bench 0.978→0.980 — **最佳P-R平衡**

**多角度路由器**(`algorithms/srs_calib.py` mode="multi-angle", 元数据(scene,dtype)驱动):

## 四、核心科学发现(四层递进)

1. **域内**: 微调330M(0.975) > GLM-5 API(0.887) > 零样本(0.715) — 轻量本地模型经领域适配可超过大模型API
2. **真实场景(v6独有判别力)**: 所有零样本方法在金标上退化为全报警, 唯难例负样本训练的v6具备判别力(clean130报警37%)
3. **判别力的边界(诚实)**: v6的判别绑定训练表面形式, 跨场景不迁移; v7多场景训练买到精确率(0.85)但引入保守偏差; mDeBERTa零样本在多文档场景反而强(0.795-0.867)但doc02模式全报警 — **内容级vs模式级判别是根本矛盾, 330M模型学到的是模式**
4. **场景先验**: 能力表56%良性(粒度惯例) vs 接口表74%真矛盾(组件缺失=数据流断裂) — 检测策略必须场景校准
