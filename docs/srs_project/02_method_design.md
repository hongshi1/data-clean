## 一、核心方法：ID-Graph（规则锚定异构文档图一致性校验）

### 科研定位

| 现有工作 | 方法 | 局限 |
|---------|------|------|
| ARTA / Bendík 2017 | 需求句对/依赖图+SAT | 不处理多模态文档结构 |
| ContractNLI | 文档级NLI(外部假设) | 不做文档内部跨位置一致性 |
| 纯LLM判断 | 直接问LLM | 不可靠(Korn 2026), 不可追溯 |
| GraphRAG/MAGE-RAG | LLM抽取建图 | 图构建噪声, 不针对一致性 |
| **ID-Graph (ours)** | **规则信号确定性产边+图上推理+证据验证** | **可追溯/无噪声/可解释** |

### 三层架构

```
┌─────────────────────────────────────────────────┐
│ L1 符号层: 12种规则信号确定性检测                  │
│   编辑距离/子串/字符集合/功能词归一化              │
│   → 检出: 7个不一致Entity(typo/truncation/多名)   │
├─────────────────────────────────────────────────┤
│ L2 图推理: 传递闭包矛盾 + 矛盾子图                │
│   A≡B, B≡C, 但A≢C → 传递闭包矛盾                 │
│   (两两比较发现不了的矛盾)                        │
├─────────────────────────────────────────────────┤
│ L3 CoVe验证: kimi起草→claude隔离验证             │
│   生成与验证解耦(解决LLM幻觉)                     │
│   → 覆盖真实矛盾 16/16 = 100%                    │
└─────────────────────────────────────────────────┘
```

### 图结构

```
节点: Entity(ID) / Mention(位置出现) / Attribute(属性值)
边:   出现边(E→M) / 属性边(E→A) / 结构边(M→Section)
图构建: 12种规则信号确定性产边(无LLM抽取)
```

### 评测结果（sc1）

| 层 | 检出 | 真实矛盾覆盖 |
|----|------|------------|
| L1符号层 | 7 Entity | 43% |
| L2图推理 | 传递闭包0 | — |
| L3 CoVe | 16 Entity | **100%** |

### 分歧案例分析

| Entity | kimi | claude | 结论 |
|--------|------|--------|------|
| PZXQ-WBJK-YYRJ | 一致 | 不一致 | "与"字语法差异, 符号层裁决=合理差异 |
| PZXQ-NBJK-WDCLFW | 不一致 | 一致 | 6个不同接口共用一个ID = 真实深层矛盾 |

## 二、三层检测管线（sc1深化）

### 名称级（字符级可解）

```
L1字符: 编辑距离≤2(typo) / 子串(truncation) / 字符集合(charorder)
L2规则: 功能词归一化(功能/服务/模块后缀)
评测: F1=0.988 (easy 90/93, medium 14/14, hard 15/15)
```

### 描述级（需NLI, 真hard）

```
对比: capability表描述 vs 正文/usecase描述
方法: 双模型NLI(kimi+claude, 严格prompt)
评测: 19/20 = 95%正确
创新: 字符级完全无法解决(措辞不同但语义相同)
```

### 语义级矛盾类型

| 类型 | 定义 | 示例 |
|------|------|------|
| truncation | 子串关系 | "交互接口"vs"交互接" |
| typo | 编辑距离≤2 | "统算"vs"通算" |
| charorder | 字符集合相同 | "对象化访问"vs"象对化访问" |
| multiname | 完全不同 | "语音交互"vs"界面配置保存" |
| semantic_conflict | 编辑距离3-8语义相近 | "连接池初始化"vs"连接池配置" |

## 三、评测协议 v2.0（防假高）

### 原则

1. **分层报告**: F1按easy/medium/hard分别
2. **真实矛盾单独**: F1_real(只看双源确认+双模型一致)
3. **hold-out**: 保留10%真实矛盾开发时不接触
4. **5基线对比**: B0多数类/B1字符级/B2 LLM/B3 NLI/B4组合
5. **统计检验**: bootstrap 95%CI + McNemar
6. **争议样本标记**: 双模型分歧的标记disputed不参与主指标

### Gold Standard可信度

| 层级 | 数量 | 验证 |
|------|------|------|
| Trust 1: 真实矛盾+双源+双模型 | 37条 | 双源100%+双模型100% |
| Trust 2: 注入+双模型一致 | 81条 | 双模型一致 |
| Trust 3: 争议(disputed) | 10条 | 双模型分歧 |
| Hold-out | 4条 | 开发完才解封 |
