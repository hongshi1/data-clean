## 二、两个关键技术设计（结构对齐发动机范式）

### 关键技术一：多粒度多模态SRS文档的自适应特征提取

对标发动机"多速率多工况时序数据的自适应特征提取"。

**难点**：
- 同一需求实体散布于正文、表格、Visio图与追溯表，粒度从章级到字符span级跨2-3个数量级
- GJB 438C刚性6章模板带来强格式共性，淹没有区分度的子系统内容个性（同"工况与健康变化耦合"）
- 文本/表格/图形三种模态异构，难以直接统一表征

**研究内容**：
- 分层粒度特征提取（章级/条目级/表行级/图节点级）
- **模板先验扣除**——以16份文档的共性模板作为"工况基线"，扣除后以残差表征编码子系统个体差异
- 跨模态配对通道构建与对齐

**技术途径**：
- 解析联邦将文档转为统一条目图
- 模板先验统计估计与残差化（GJB 120条规则库转译为模板约束）
- 冻结编码器多头投影+结构化门控
- 以跨文档对齐F1消融验证残差表征增益

**具体问题举例**（对应发动机的"阶次域/温压基线"）：
- "响应时间"在16份文档中都出现在3.11节（模板共性），但具体值从10ms到600ms不等（子系统个性）——**原始表征会被模板共性淹没，残差表征保留个性信号**
- 接口表在所有文档中都有"发送方/接收方"列头（模板），但具体接口拓扑不同（个体）

### 关键技术二：弱标签条件下可迁移需求表征与证据级判定构造

对标发动机"弱标签条件下的可迁移表征与事件级证据构造"。

**难点**：
- 确认违例样本稀缺（仅17条gold违例+227候选）
- silver标签含显式标识符词面捷径（预注册实验已证实AUC差0.2358）
- 16份子系统文档分布差异大，小样本跨域易过拟合
- 检测须输出可核验证据而非仅二分类结论

**研究内容**：
- **去捷径对比表征**（含ID/不含ID分层评测已预注册）
- **跨文档迁移学习**（文档级4-fold + leave-one-doc-out）
- **证据级判定与定位联合构造**（verdict∧evidence_refs联合评分，非二分类）

**技术途径**：
- 显式标识符分层评测协议（预注册于48号文档）
- 文档级fold防泄漏+同源实体族隔离
- 判定与定位联合评分协议（108条定位gold在建）
- 小样本报Wilson置信区间与学习曲线

**具体问题举例**：
- 16份文档中"同名异义"（如"数据获取"在不同文档指不同功能）→ 跨文档迁移须泛化
- 违例检出须给出"哪条需求、哪个位置、什么类型的证据"→ 证据级判定

## 三、可行性诚实评估

**站得住的创新点**：
1. **模板先验扣除（残差表征）**——GJB刚性结构使"共性/个性分解"可形式化、可消融，发动机场景反而无此便利条件
2. **去捷径+跨文档迁移**——有现成实验协议（预注册+文档级fold+Wilson CI）
3. **证据级判定**——直接衔接S7定位gold，可评可验证

**凑数风险（须避免）**：
- "多速率"无时间轴支撑→任务书不写"时序"字样，改用"多粒度/多模态"
- 16份=16个迁移域，统计功效弱→只报置信区间+学习曲线，不宣称"可迁移表征学习"大结论
- 自监督表征在无大规模语料下难出独立贡献→只作通道特征，不单列创新点

## 四、任务书可写文本（三段式）

**关键技术一：多粒度多模态需求文档自适应特征提取**

技术难点：同一需求实体散布于正文、表格、图形与追溯表等不同位置，描述粒度从章节级到字符级跨多个数量级；文档模板的格式共性淹没子系统个体的内容差异性；文本、表格、图形三种模态信息表达形式各异，难以直接统一表征。

研究内容：分层粒度特征提取；以文档共性模板为先验、扣除后以残差表征编码个体差异；构建跨模态配对通道并对齐。

技术途径：将文档解析为统一条目图；进行模板先验统计估计与残差化；融合冻结编码器多头投影与结构化门控；以跨文档对齐准确率消融验证残差表征增益。

**关键技术二：弱标签条件下可迁移需求表征与证据级判定构造**

技术难点：确认违例样本稀缺且弱标签含标识符词面捷径；各子系统文档分布差异大，小样本跨域易过拟合；检测结果须附可逐项核验的证据而非仅输出分类结论。

研究内容：去捷径对比表征；跨文档迁移训练；证据级判定与定位联合构造。

技术途径：建立含标识符与不含标识符分层评测协议；采用文档级交叉验证防泄漏；构建判定与定位联合评分体系；以置信区间与学习曲线报告小样本条件下的统计可靠性。
