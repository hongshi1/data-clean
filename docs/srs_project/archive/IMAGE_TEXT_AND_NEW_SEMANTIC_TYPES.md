# 图片-文本不一致检测 + 语义不一致新类型 — 调研报告

> 数据集检查: PURE 62个SRS文档中，**12/20个文档含图片**（共14,738张图片），**28/62个文档含图片引用**（共469次"Figure X"引用），**22/62个文档含表格引用**（共462次"Table X"引用）。

---

## 一、数据中的图片情况

| 检查项 | 结果 |
|---|---|
| 含图片的文档 | 12/20 (60%) |
| 总图片数 | 14,738张 (gemini.pdf占14,377张) |
| 含"Figure X"引用的文档 | 28/62 (45%) |
| 总图片引用数 | 469次 |
| 含"Table X"引用的文档 | 22/62 (35%) |
| 总表格引用数 | 462次 |
| 图片引用最多的文档 | telescope.pdf (80次), peppol.pdf (80次) |

**结论**: SRS文档中大量存在图片和表格引用，图片-文本不一致检测有实际数据基础。

## 二、图片-文本不一致检测技术

### 2.1 可检测的不一致类型

| 编号 | 不一致类型 | 问题描述 | 举例 |
|:---:|---|---|---|
| F1 | 图文内容矛盾 | 文字描述与图片内容不一致 | 文字说"响应时间≤50ms"但图表显示100ms |
| F2 | 图表-表格数据矛盾 | 图表中的数值与表格中的数值不一致 | 图表显示吞吐量200Mbps，表格写100Mbps |
| F3 | 图片引用断裂 | "见图3"但文档中没有图3 | "as shown in Figure 5"但无Figure 5 |
| F4 | 图片标注与正文矛盾 | 图片标注的参数名/值与正文不一致 | 图中标注"temperature 80°C"，正文写"50°C" |
| F5 | 流程图与文字描述矛盾 | 流程图的步骤与文字描述的步骤不一致 | 文字说"A→B→C"，流程图显示"A→C→B" |

### 2.3 我们可以做什么

| 优先级 | 检测项 | 方法 | 所需资源 | 难度 |
|:---:|---|---|---|:---:|
| **P0** | F3 图片引用断裂 | 正则提取"Figure X"引用 → 检查文档中是否存在对应的Figure | 无(纯规则) | ★☆☆ |
| **P1** | F1 图文内容矛盾 | 用GLM-5多模态: 提取图片+正文，让LLM判断是否一致 | GLM-5 API(需多模态) | ★★☆ |
| **P1** | F2 图表-表格矛盾 | 提取图表数值(OCR/表格抽取) + 表格数值 → 比较 | OCR + 表格抽取 | ★★☆ |
| **P2** | F4 图片标注矛盾 | OCR提取图片标注文字 → 与正文比较 | OCR | ★★☆ |
