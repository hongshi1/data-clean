## 数据集

**自建（上下文关联）**：16份真实GJB 438C军用SRS，构建"表格深度检索"（438查询×1,207表格）与"软件图片"（899查询×379图）两个场景。

**自建（一致性校验）**：16份真实GJB 438C军用SRS，构建"答案一致性校验"（91查询×574证据块，三态判定silver标签，29主题簇held-out切分46查询）、"跨文档泛化"（06号文档30查询×构造性sound标签）与"真实违例检测"（17条人工深读违例×构造断言QA）三个场景。

**WTQ**：维基百科表格问答（Pasupat & Liang, ACL 2015），18,486查询×2,100表格。
**FeTaQA**：自由形式表格问答（Nan et al., ACL 2022），2,000查询×2,003表格。
**DuRetrieval**：中文段落检索基准（Du et al., SIGIR 2022，C-MTEB收录），2,000查询×10,000段。

（注：一致性校验部分无公开对标基准——GJB军用SRS的三态一致性校验在公开文献无先例，基准本身即贡献之一。）

## 两部分的关系（流水线）

```
表1(上下文关联/证据召回) → 冻结证据 → 表2/表3(一致性校验/三态判定)
```

数据资产, 评测协议各自独立(R@1 vs macro-F1/检出率)。
