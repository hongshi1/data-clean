# 评测协议设计 v1.0

日期: 2026-08-08
状态: 草案(待方法设计后修订)
依据: 数据资产最终状态(2184条QA)

## 1. 评测目标

评测"上下文关联+一致性校验"流水线的三层检测能力:
- 语法层: 不依赖上下文, 直接比对GJB规则
- 语义层: 依赖召回的多模态上下文(文本+表格+图片), 验证claim
- 逻辑层: 依赖上下文+专家知识, 检测逻辑漏洞

## 2. 数据集划分原则

### 2.1 划分维度

| 维度 | 原则 | 理由 |
|------|------|------|
| 文档级隔离 | train/test按文档划分, 同一文档的QA不跨split | 防止模型记忆文档内容(文档级泄漏) |
| 指令分组隔离 | 同一instruction的正负对不跨split | 防止模型记忆"指令→答案"捷径 |
| 场景分层 | 语义层按场景分别评测+整体 | 分析多模态贡献 |

### 2.2 划分冲突处理

当"文档隔离"与"指令隔离"冲突时(同一指令只出现在一个文档, 天然同时满足): 
- **以文档隔离为主**: 同文档所有QA进同一split
- 指令隔离自动满足(每个instruction属于唯一文档)

### 2.3 实际划分

```
train: 文档01-08 (8份, 原生QA约710条)
test:  文档09-16 (8份, 原生QA约360条)
```

train/test比例约 2:1。外部数据(ContractNLI/Fault-prone/FinBalance)作为**泛化测试集**单独评测(不与原生混合), 因source和任务类型不同。

## 3. 各层评测协议

### 3.1 语法层(180条: 91负+89正)

- 任务: 二分类(合规/不合规), 输入{instruction, output}, 输出label
- 指标: P/R/F1, 宏平均
- 基线: 多数类准确率(89/180=49.4%)
- 数据: syntax_check_data.json的91条负例(qualification_section_mismatch) + 91条正例
- 注意: 语法层不需要文档检索(检测对象在instruction+output内), 可单独评测

### 3.2 语义层(864条: 436正+428负)

- 任务: 验证output是否与召回上下文一致(三态: entailed/contradicted/baseless)
  - entailed = output与文档一致(正例)
  - contradicted = output与文档矛盾(负例)
  - baseless = 召回上下文无相关信息(未建模, 本期二态)
- 指标: 按场景分别评测 P/R/F1 + 整体宏平均
- 基线:
  - 多数类准确率(436/864=50.5%)
  - 无检索基线(仅指令, 无上下文): 报告差值量化上下文价值
- 场景分布: sc1:691 / sc3:54 / sc4:54 / sc5:57 / sc0:8
  - sc0(version_conflict 8条)因数据过少, 合并入整体评测, 不单独报告
- 指令分组: 423组, 305组单条+118组多条
  - 评测时**每组至多抽1条**(按label均衡), 防止同指令重复影响
  - 或全量评测但按组加权

### 3.3 逻辑层(117条: 全负例)

- 任务: 二分类(有逻辑漏洞/无漏洞)
- 指标: P/R/F1
- 现状: 117条全部为负例(dangling_exception_reference 62 + 抢救的55条)
  - **无正例** → 需补充正例或标注"无漏洞"对照
  - 建议: 从用例表随机抽等量"异常流定义完整"的QA作为正例(待办)

### 3.4 外部泛化测试(946条)

- ContractNLI 546条(正432/负114): 文档级NLI, 泛化能力
- Fault-prone SRS 200条(正49/负151): 需求歧义检测
- FinBalance 200条(正100/负100): 数值一致性
- 指标: 各数据集分别P/R/F1 + 整体
- 基线: 多数类(ContractNLI 79.1%, Fault-prone 75.5%, FinBalance 50%)
- 注意: ContractNLI output统一常量, 模型必须查文档

## 4. 评测流程

```
输入: {instruction, output, doc_ref, scenario}
1. 上下文关联组件: 按instruction召回文档上下文(文本+表格+图片)
2. 校验组件: 基于召回上下文验证output
3. 输出: {label, confidence, evidence}
4. 评分: 与gold label比对, 计算P/R/F1
```

## 5. 消融实验

| 消融 | 设置 | 验证点 |
|------|------|--------|
| 无上下文 | 仅指令→直接判断 | 上下文关联的价值 |
| 无图片 | 只给文本+表格, 不给图片路径 | 多模态(图片)的价值 |
| 无表格 | 只给文本+图片 | 表格模态的价值 |
| 纯LLM | 不召回, LLM直接答 | RAG vs 纯LLM |
