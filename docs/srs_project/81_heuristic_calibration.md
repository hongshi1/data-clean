## 四、过程教训（记录）

扫描初版打印出现"非单调"假象(ms=4: 959>ms=3: 409)——
**根因是控制台编码错位**：`平行对{len}`的中文UTF-8字节在GBK终端解码
时错位, 末字节与数字首位组合成乱码字, 吞掉首位数字
(3555→555/3481→481/1959→959)。修复: 打印改ASCII标签+JSON为权威
数字。**教训固化: 跨编码终端上, 数字前避免直接拼接中文。**
