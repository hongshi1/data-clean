# 医疗不一致检测方法总表

> 详细讲解见各类专题文档。

## 总表

| 编号 | 方法名 | 核心思路（大白话） | 关键指标 | 成熟度 |
|---|---|---|---|---|
| | **A. 图像↔报告一致性检测** — 检测"片子看到的"vs"报告写的" | | | |
| A1 | 冲突矩阵 | AI看片出每病种概率，报告NER出四态(有/没有/可能/没提)，逐病种交叉比对，5类冲突+严重度 | 62冲突/20样本 | ★★★★☆ |
| A2 | CheXzero对齐 | 把胸片和报告都变成512维向量，算余弦相似度——像把两段话翻译成同一种"数字语言"再比距离 | 零样本接近监督 | ★★★☆☆ |
| A3a | FAMDR | 不把图文差异"抹平"，反而**保留差异**当冲突线索→定位到哪个像素区域与哪句话矛盾 | F1=0.83 | ★★☆☆☆ |
| A3b | Phrase-grounded | 把报告里的"发现"和"位置"故意改错(右侧→左侧)造训练数据→模型学会检测事实错误 | 相关系数0.997 | ★★★☆☆ |
| A4a | CheXagent | 一个大模型同时看图+读文+做推理，直接输出"图和报告一致吗"——像医生同时看片子和报告 | 省36%时间 | ★★☆☆☆ |
| A4b | VDC | 针对每个标签生成问题("图里有积液吗？")→AI看图回答→数答对几个算一致性分数 | TPR 99.91% | ★★☆☆☆ |
| | **B. 报告内一致性检测** — 检测报告自身内部矛盾 | | | |
| B1 | NLI矛盾 | Findings段当前提、Impression段当假设，做自然语言推理——前提是否支持假设？ | — | ★★☆☆☆ |
| B2 | 三态聚合 | 同一报告内多处提到同一疾病时，按阳性>不确定>否定优先级合并→合并过程中消解了矛盾=报告内部有表述冲突 | κ>0.6 | ★★★☆☆ |
| B3 | 逻辑推理链 | 构建"积液→导致→肺不张"的推理链，如果Findings提了积液但Impression没提肺不张→推理链断裂=逻辑不完整 | 一致性提升 | ★☆☆☆☆ |
| | **C. 标签一致性检测** — 检测CheXpert自动标签与数据的不一致 | | | |
| C1 | DeFT | 给每个疾病学两个文本描述(正描述揭示特征+负描述当阈值)，图像与正描述更像=标签对，与负描述更像=标签错 | P/R 85.81/85.72 | ★★★☆☆ |
| C2 | CLIPCleaner | 用CLIP零样本分类器给每个样本打分→按分数排序→高分=干净样本，低分=可能有噪声 | 74.83% | ★★★☆☆ |
| C3 | Cleanlab | 统计"模型预测的概率"和"给定的标签"的关系→概率和标签经常不一致的样本=可能有噪声 | — | ★★★★☆ |
| C4 | 互斥约束 | "No Finding"(无异常)和其他13种诊断不能同时为阳性——逻辑上"没病"和"有胸腔积液"不能共存 | ✅ 已验证 | ★★★★★ |
| | **D. 临床知识一致性检测** — 检测数据与临床医学知识的不一致 | | | |
| D1 | 三层规则库 | L1每个指标查正常范围→L2血检超标但诊断说没病→L3多个指标组合异常(乳酸高+pH低=酸中毒) | 1444冲突/10k | ★★★★★ |
| D2 | LLM+Guard | LLM理解"乳酸高=酸中毒"的语义→但LLM可能搞错数字→代码核验"乳酸到底超没超"→Guard后误报归零 | FP=0 | ★★★★☆ |
| D3 | KGDMC | 把医学知识画成关系网(肌酐→肾衰→高钾)→沿网推理→推理链走得通=自洽，断了=矛盾 | — | ★★☆☆☆ |
| D4 | Hybrid-Code v2 | AI先猜答案→5道规则关卡审查(格式对?有证据?被否定?时间矛盾?互斥?)→全过才输出→零幻觉 | 0%幻觉, 85%覆盖 | ★★★☆☆ |
| D5 | 知识嵌入审查 | 综述：三条路把知识塞进LLM(训练时背/推理时查百科/推理时给参考资料)+五层知识源从靠谱到不靠谱 | — | ★★☆☆☆ |
| D6 | LLM合规检查 | 以前要把临床指南翻译成计算机规则(费时数月)→现在让LLM直接读指南原文+患者数据→判断治疗是否合规 | — | ★★☆☆☆ |
| D7 | RadGraph奖励 | 用标注好"实体-关系"的报告数据集做奖励信号→AI生成的报告实体和关系对了就奖励→RL训练到事实正确 | +14.2%/+25.3% | ★★★☆☆ |
| | **E. 生成幻觉检测** — 检测AI生成内容与图像/事实的不一致 | | | |
| E1 | HalluCXR | 把AI生成报告的幻觉分8类(属性/对象/数量/位置/错觉/方向/文本/关系)+打临床严重度分 | 61.9-82.3%含幻觉 | ★★★☆☆ |
| E2a | DSE语义熵 | AI对同一张图回答15次→15个回答一致=可信/各不相同=可能幻觉→高熵=有冲突 | 51.7%→76.3% | ★★★☆☆ |
| E2b | UniVRSE | 报告拆成原子事实("心影增大""右侧积液")逐条验证+故意模糊图像看AI是否还依赖视觉 | 6数据集超越 | ★★☆☆☆ |
| E3 | CoEV | 双向验证:文本说的在图里找证据+图里有的在文本找提及→四象限(一致/漏写/矛盾/无关) | PR-AUC+3.0% | ★★☆☆☆ |
| E4 | 反事实扰动 | 把"胸腔积液"换成"气胸"→如果AI给两个词相同的图像定位区域→说明AI没真"看到"它在幻觉 | 持续提升 | ★★☆☆☆ |
| E5 | MedHEval | 把幻觉按成因分3类:看错了(视觉误判)/不懂(知识缺乏)/答非所问(上下文错位)→不同成因不同解法 | 11个LVLM评估 | ★★★☆☆ |
| E6 | SC-UQ | 多次生成报告→语义一致性低的=高不确定性=可能幻觉→不修改模型即插即用→拒20%报告提10%事实性 | +10%事实性 | ★★★☆☆ |
| E7 | VGS-Decoding | 关键洞察:幻觉词在图像模糊时概率不降(靠语言先验)→解码时逐词调整:视觉依赖的放大,不依赖的抑制 | +9.12%, 2×开销 | ★★☆☆☆ |
| E8 | Med-VCD | 选出"视觉信息词"只对它们做对比解码→不用跑两遍解码→更快 | +13%准确率 | ★★☆☆☆ |
| E9 | 实体+NLI奖励 | 三个奖励:生成的疾病实体对不对(F1)+描述是否推理一致(NLI)+语义像不像(BERTScore)→RL训练 | F1+22.1 | ★★★☆☆ |
| E10 | MEDLAYXPLAIN | 同一图像生成专家版+外行版报告→两版在事实层面应一致(只是表述不同)→事实矛盾=幻觉 | — | ★☆☆☆☆ |
| | **F. 跨数据集/时序一致性检测** — 检测跨机构/跨时间的不一致 | | | |
| F1 | 域偏移检测 | 在MIMIC上训练的方法迁到NLMCXR→测标签一致率和AUPRC下降多少→下降多=域偏移严重 | AUPRC下降 | ★★★☆☆ |
| F2 | 纵向时序 | 同一患者多次就诊:疾病进展应逻辑一致(阳性→消退→阴性)→出现"阳性→阴性→阳性"=可能配对错或诊断不一致 | — | ★☆☆☆☆ |
| F3 | DICOM时戳 | 比较图像检查时间和报告签署时间→差>30天=可能旧片配新报告+患者ID和体位也要一致 | — | ★★★★☆ |
| F4 | 因果域偏移 | 用因果图区分3种偏移:图像分布变了(协变量)/疾病流行率变了(标签)/疾病-图像关系变了(概念)→不同偏移不同检测策略 | — | ★★☆☆☆ |
| F5 | 协同域适应 | 同一张片子在不同医院AI给出不同诊断→测诊断一致率+域适应对齐特征分布减少差异 | — | ★★☆☆☆ |

## 速查：按问题找方法

| 你要检测的问题 | 方法 | 一句话 |
|---|---|---|
| AI看到病灶但报告说没有 | A1 | 逐病种概率×四态比对 |
| 哪个像素与哪句话矛盾 | A3a FAMDR | 保留差异特征定位 |
| 胸片报告的疾病发现和位置对不对 | A3b Phrase-grounded | 扰动+对比回归 |
| 图和报告整体匹配吗 | A2 CheXzero | 向量余弦相似度 |
| 报告正文和结论自相矛盾 | B1 NLI | Findings vs Impression蕴含推理 |
| CheXpert标签标错了 | C1 DeFT | 双重prompt检测 |
| 标签之间逻辑矛盾(No Finding+有病) | C4 | 互斥约束 |
| 血检异常但诊断说没病 | D1 规则库 | 三层递进规则 |
| 血检和诊断的复杂语义矛盾 | D2 LLM+Guard | LLM判断+代码核验 |
| 要求零幻觉的安全场景 | D4 Hybrid-Code | 神经生成+符号验证 |
| AI生成的报告有没有幻觉 | E6 SC-UQ | 即插即用不确定性量化 |
| 幻觉是什么类型的 | E1 HalluCXR | 8类分类+严重度 |
| 幻觉是什么原因产生的 | E5 MedHEval | 3类成因(看错/不懂/答错) |
| 推理时抑制幻觉 | E7 VGS-Decoding | 视觉退化时幻觉词概率不降 |
| 跨数据集标签还可靠吗 | F1 | 测AUPRC衰减 |
| 旧片子配了新报告 | F3 | DICOM时戳校验 |
| 随访报告和上次矛盾 | F2 | 疾病进展序列逻辑校验 |
